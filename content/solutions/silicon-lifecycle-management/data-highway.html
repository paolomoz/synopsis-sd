Intelligent Data Extraction & Communication

The importance of embedding monitors and a test network in modern day SoC's is well understood. To maximize the value of these monitors and the test network, they should be accessible at all phases of a silicon device's lifecycle. The infrastructure for data extraction and communication connects all the monitors on silicon together and makes them accessible to the system for further data processing. The data highway infrastructure should be easy to implement and flexible with low overhead.

Synopsys SLM portfolio provides products which form the SLM data highway.
