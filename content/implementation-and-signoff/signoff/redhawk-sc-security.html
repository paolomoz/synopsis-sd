Get Started

Identify Pre-Silicon Hardware Security Vulnerabilities from RTL to Layout

Synopsys RedHawk-SC Security™ is the most comprehensive EDA solution for pre-silicon side-channel analysis, identifying hardware security vulnerabilities in IC layouts. Leveraging advanced multiphysics simulation, it detects physical side-channel leakage through power noise, electromagnetic emissions, and thermal profiling. This empowers design teams to ensure confidential data and cryptographic keys are secure before committing to manufacturing.

Features

Comprehensive Side-Channel Coverage

Comprehensive Side-Channel Coverage

RedHawk-SC Security analyzes power, electromagnetic, and thermal leakage across all physical design stages. It supports standard cryptographic systems such as AES and custom models, ensuring robust protection against a wide range of hardware attacks.

Built-In Security Metrics and Analytics

Built-In Security Metrics and Analytics

Integrated analytics deliver T-score, SMTD, and sensitivity scoring to quantify vulnerability and the effectiveness of design countermeasures. Secret-key disclosure reports and electromagnetic field profiling provide actionable security insights.

Fast, Cloud-Optimized Simulation

Fast, Cloud-Optimized Simulation

Built on the SeaScape elastic compute architecture, RedHawk-SC Security processes large multiphysics models and millions of activity cycles rapidly. Big-data techniques enable near-linear scalability and efficient resource usage.

No-Touch Probing of Side-Channel Leakage

No-Touch Probing of Side-Channel Leakage

Patented simulation technology enables simulation of no-touch probing of EM leakage for both on-chip and near-field above the chip surface, providing a practical approach to side-channel analysis without hardware testing.

Root Cause Identification and Countermeasure Assessment

Root Cause Identification and Countermeasure Assessment

Pinpoints leakage sources and evaluates the strength of design countermeasures, helping engineers modify layouts to mitigate vulnerabilities before fabrication.

Supports Long Activity Vectors

Supports Long Activity Vectors

Processes very long switching scenarios, generating security-aware probing configurations for complex functional vectors.

Intuitive Security Insight GUI

Intuitive Security Insight GUI

Graphical feedback and rich metrics make vulnerability analysis accessible for teams with limited hardware security expertise, streamlining risk assessment, and design optimization.

FAQ

What types of side-channel vulnerabilities does RedHawk-SC Security detect?

It identifies leakage risks via power noise, electromagnetic emissions, and thermal profiling at RTL and layout stages.

Can RedHawk-SC Security assess standard cryptographic systems?

Yes, it supports AES and custom models, reporting key disclosure metrics and vulnerability scores.

How scalable is RedHawk-SC Security for large designs?

Built on the cloud-optimized SeaScape elastic compute platform, it efficiently simulates millions of cycles for extensive activity vectors.

Is physical hardware required for side-channel analysis?

No, patented algorithms enables simulation of no-touch probing of EM leakage for both near-field and on-chip.

How are countermeasures evaluated?

Integrated analytics score the strength of design countermeasures, helping teams optimize security pre-silicon.
