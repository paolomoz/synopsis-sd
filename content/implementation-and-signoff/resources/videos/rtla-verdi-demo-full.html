RTL Architect & Verdi Debug System Integration

The integration of Synopsys RTL Architect with the Synopsys Verdi debug system environment provides an easy way to get earlier insights into PPA issues, so these problems can be resolved for an overall better product and faster RTL closure.

In this technical demo we will show you how to easily:

  • Launch Verdi from RTL Architect to load and view PPA and KDB data together
  • View, trace, and investigate congestion data
  • Cross-probe between the tools for fast analysis and debug
