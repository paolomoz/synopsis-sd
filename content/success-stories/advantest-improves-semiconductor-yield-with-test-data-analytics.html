Overview

Advantest Corporation is a leading manufacturer of automatic test equipment (ATE) for the semiconductor industry, as well as measuring instruments for electronic systems, including fiber optic and wireless communications equipment and digital consumer products. Based in Tokyo, Advantest produces Memory, SoC, and RF test systems. Their innovative technology enables real-time data streaming and analytics, helping chipmakers enhance yield, reduce costs, and ensure quality. Advantest collaborates with various semiconductor fabless companies, foundries, and outsourced semiconductor assembly and test (OSAT) facilities to deliver cutting-edge solutions.

Challenges

Advantest faced several significant challenges that impacted their operations:

  • Manual Data Collection: Traditionally, data collection and analysis were manual processes, leading to delayed insights.
  • Diverse Ecosystem: Manufacturing and test operations are spread across the globe, generating high volumes of diverse chip data in different formats, making data management challenging.
  • Costly Retests: Delayed identification of issues can lead to repeated and costly tests or, worse, failed die, significantly impacting the bottom line.

Solution

Advantest and Synopsys developed an innovative real-time data analytics solution to address these challenges. The solution integrates Advantest Cloud Solutions™ (ACS) Nexus for real-time data streaming with Synopsys SiliconDash analytics. Key features include:

  • Automated Data Streaming: Continuous data collection from testers to analytics tools via API, eliminating manual processes.
  • Real-time Analytics: Instant access to dashboards, visualizations, and reports, enabling prompt issue identification and resolution.
  • Enhanced Security: Secure and reliable data collection, mitigating risks of data interception.
  • Edge Computing: High-performance edge computing for immediate decision-making during test execution.

Results

The implementation of the real-time data analytics solution yielded remarkable results:

  • Improved Yield: Prompt root-cause identification and real-time production control significantly increased yield rates.
  • Cost Savings: Automated data analytics reduced the need for retests, saving substantial costs.
  • Enhanced Quality: Real-time screening for outliers and quality control minimized quality escapes.
  • Operational Efficiency: Streamlined data management and automated insights improved overall operational efficiency.

The collaboration between Advantest and Synopsys has revolutionized semiconductor manufacturing, providing real-time insights that drive productivity, quality, and cost efficiency.
