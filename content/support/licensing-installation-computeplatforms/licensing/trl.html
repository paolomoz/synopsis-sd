Tamper-Resistant Licensing Format Change Requires SCL 2018.06

Due to an upcoming license format change, all customers must upgrade to Synopsys Common Licensing 2018.06 by December 10, 2018. (SCL 2018.06 is based on FlexNet 11.14.1.3 technology.)

This upgrade is required to be able to serve license keys in the Tamper-Resistant Licensing (TRL) format, which will be issued to Synopsys customers starting December 10, 2018. (Older versions of SCL are not able to serve TRL-format licenses.)

For more details on the license key file format change, see the customer announcement.

Additional Resources

  • To download Synopsys Common Licensing 2018.06, browse to
    https://solvnet.synopsys.com/DownloadCenter/dc/product.jsp and choose Synopsys Common Licensing.
  • For SCL installation and setup help, open a Support case through SolvNet at http://www.solvnet.com and choose Synopsys Common Licensingas the product.
  • For further information on SCL, visit http://www.synopsys.com/licensing
