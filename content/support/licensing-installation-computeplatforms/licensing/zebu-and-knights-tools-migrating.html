Starting with the December 2013 tool release, former EVE ZeBu and Magma Knights tools will migrate to Synopsys Common Licensing (SCL). Besides ZeBu, the following Synopsys/Magma Knights products will be affected by this change: Camelot, SystemNav, kDBI, kDBIlib, Excalibur and Yield Manager.

The migration to SCL means that starting December 2013:

  • SCL 11.7 will be released
  • License keys for tools based on the eved and knights vendor daemons will be reissued in the Synopsys combined vendor daemon (cvd) format
  • Standard cvd-format license keys will be available for download at the SmartKeys Website

The cvd-format keys will require Synopsys Common Licensing version 11.7. Instructions for setting up and starting SCL version 11.7 will be posted online in the Synopsys Licensing QuickStart Guide

Important:
You will be required to migrate to SCL version 11.7 if you have ZeBu or Knights features and you move to a new license file issued on or after December 6, 2013. Activities that could trigger the required upgrade include:

  • Retrieving a new keyfile from SmartKeys
  • A new or renewal order is placed
  • Keys are remixed or extended
  • Keys are rehosted

SCL version 11.7 provides the following benefits:

  • Compatibility with new tool releases
  • Backward compatibility with older ZebU and Magma Knights tool releases
  • A simplified licensing setup (one license file, one vendor daemon) for all Synopsys products
  • A 24x7 license key retrieval mechanism, available at SmartKeys.

How to Migrate to Synopsys Common Licensing
In December 2013, you will receive a single license cvd-format file for both ZeBu and Knights products. To use this license file, the following actions must be taken:

  1. Make sure your license server OS is supported by Synopsys Common Licensing. See the list here.
  2. Download and Install SCL version 11.7
  3. Customize the new cvd-format license file (SERVER and VENDOR lines)
  4. Bring down the eved and knights daemons (including lmgrd)
  5. Bring down SCL / snpslmd (if running)
  6. Start the SCL version 11.7 vendor daemon
  7. Make sure the LM_LICENSE_FILE user environment for Zebu and Knights users is updated

This migration will not require you to update your tool versions, as Synopsys Common Licensing version 11.7 will be able to support older versions of your tools.

Plan your migration to SCL version 11.7 now.
