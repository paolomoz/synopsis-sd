How Do I Order a FlexNet Dongle for Synopsys Tools?

Question:

How do I order a FlexNet (Flexlm) dongle for use with Synopsys tools?

Answer:

For new orders for PrimeSim HSPICE and certain other tools, you might be able to obtain a dongle from Synopsys. Inquire with your sales Account Manager.

Alternatively, you can order FlexNet-compatible dongles from the FlexNet technology vendor, Revenera (formerly Flexera). Follow this procedure:

  1. Contact Revenera to request a quote and to place your order for a FLEXID-10 USB dongle. (The shorter, Synopsys-supported FLEXID-9 USB dongles might also be available.)

    Dongle request e-mail address: [email protected]

  2. After you have received the dongle, pass the dongle hostid information on to your Synopsys sales representative. The dongle hostID (needed for "cutting" your license key file) is printed on the dongle and has a "FLEXID=" prefix followed by an 8-character suffix. For example: FLEXID=10-12345678 (WibuKey USB dongle).

    Except for maintenance renewals, orders are no longer accepted for licenses for Rainbow/Sentinel USB dongles (FLEXID=7-) or Dallas (FLEXID=8-) parallel port dongles.
    Note: Synopsys no longer supports the Sentinel SuperPro dongles on the Linux OS. (For SuperPro dongles on the Windows OS, only uncounted licenses are supported.) If you have such licenses, contact your Synopsys Account Manager to request a replacement dongle and a new license file for the new FLEXID hostid.

  3. If this order is related to the rehost of an existing license file, you must fill out a "rehost form," obtainable from your Account Manager. Off-support licenses cannot be rehosted.

  4. If necessary, install the correct dongle driver. For SCL, the drivers are in the scl_root/<platform>/drivers directory. For example, on the Windows platform, the FLEXID 9 driver is at scl_root/win32/drivers/SCL_FLEXID9_Installer.exe.

    Click here for help on installing the FLEXID dongle drivers.

  5. For counted licenses only, SCL is also required. (SCL is not required for uncounted, or serverless, licenses.) From SolvNet, download and install the latest SCL version for Windows or Linux.

    For details on how to start SCL on the Windows OS, click here

Question:

What kinds of FlexNet ID (FLEXID) dongles are supported?

Answer:
Synopsys recommends that customers use FLEXID 10 USB “WibuKey” dongles, which can be purchased directly from Revenera. Up to three WibuKey dongles are supported per Windows or Linux machine.

Limitation: Some older Synopsys software might not work with the FLEXID 10 dongles. Software built on FlexNet 11.9 and later should be compatible with the newer FLEXID 10 dongles. In general, this means that Synopsys tool versions 2015.06 and later will be compatible.

Question:

Does Synopsys support FLEXID 9 dongles?

Answer:
If you wish to use FLEXID 9 USB dongles, note that Synopsys only supports the shorter dongles (such as the HASP HL H4M4), which measure 1.57 inches long.

Support for the longer, legacy 2-inch USB dongles (such as HASP 4 M1 from Aladdin / SafeNet) is being “end of lifed” by Flexera, which will no longer provide updated drivers for the longer dongles.

Synopsys tools versions after 2017.06 might not be compatible with the longer, legacy dongles.

Question:

Can dongles be used in conjunction with virtual machines?

Answer:
Revenera does not recommend using FLEXID (dongle) hostids for license servers (such as the Synopsys SCL license server) running in virtual machines. This is because there are two separate third-party layers where an issue could occur: the dongle driver and the hypervisor USB-passthrough feature. Bugs in either of these layers could not be fixed directly by Synopsys or Revenera.
