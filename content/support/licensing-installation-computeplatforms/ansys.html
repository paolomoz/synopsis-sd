Ansys Semiconductor Licenses

Now Delivered From SmartKeys

Change in License File Delivery for Ansys Semiconductor Products

As part of the integration of Ansys into Synopsys, on December 8, 2025, license files for Ansys Semiconductor products will migrate to the Synopsys SmartKeys key retrieval system currently used for downloading other Synopsys license files. The Ansys Semiconductor license files downloaded from SmartKeys will be separate from other Synopsys license files and will remain compatible with the Ansys License Manager and daemon (ansyslmd).

This change does not affect Ansys non-Semiconductor licenses, which will still be available through the Ansys Licensing Portal.

For your convenience, the Ansys License Manager will also be available in the Synopsys SolvNetPlus Download Center.

To allow for convenient license management, Ansys Semiconductor and non-Semiconductor licenses are delivered in separate files, as described below. The Ansys License Manager seamlessly loads multiple license files from the same directory.

Ansys Semiconductor FSA Orders
Ansys Semiconductor FSA Orders are now handled from the Customer Self Service website. For more information on this transition, see the CSS FSA help page. Note that this transition does not affect Ansys non-Semiconductor products.

Ansys Semiconductor License File Downloads

Starting December 8th, Ansys Semiconductor license files must be downloaded from the SmartKeys link in the SolvNetPlus Download Center, or from https://www.synopsys.com/smartkeys.

The Ansys keys will be in a separate file from the Synopsys “SCL” (snpslmd) keys and should not be merged
with the SCL keys. Licenses for Ansys Semiconductor products will be contained in a file named
Synopsys_Key_Site_nnnn_Server_nnnnn_ansyslmd.txt.

Licenses for all other Ansys products will remain in the file named ansyslmd.lic and will continue to be downloaded from the Ansys Licensing Portal.

Ansys License Manager Setup

  1. If you are installing Ansys products for the first time, download the Ansys License Manager from the SolvNet Download Center at: https://solvnet.synopsys.com/DownloadCenter.
  2. Download your license file(s) from SmartKeys.
  3. Only for license files where the VENDOR line refers to the ansyslmd daemon, follow the instructions below.

Add or Replace the Ansys Semiconductor License File in the license_files Directory

  1. After installing the Ansys License Manager, the resultant fileset includes a license_files directory. Copy the downloaded license file into the license_files directory:
    • On Linux, the default installation directory is /ansys_inc/shared_files/licensing/license_files
    • On Windows, the default installation directory is C:\Program Files\Ansys Inc\Shared Files\Licensing\license_files
  2. Rename the license file from SmartKeys, replacing the .txt file name extension with the .lic extension.
    • You may rename the license file to any *.lic name that is unique.
    • Do not overwrite the ansyslmd.lic file, if present.
      For example, for Linux:
      % pwd
      /ansys_inc/shared_files/licensing/license_files
      % mv Synopsys_Key_Site_nnnn_Server_nnnnn_ansyslmd.txt ansyseda.lic
      OR
      % mv Synopsys_Key_Site_nnnn_Server_nnnnn_ansyslmd.txt \
      Synopsys_Key_Site_nnnn_Server_nnnnn_ansyslmd.lic
  3. Make sure the license file has read permissions. For example, for Linux:
    % chmod 644 ansyseda.lic

NOTE: If temporary keys are sent to you outside of SmartKeys (for example, through emails from sales or sales support), they should be kept separate from your SmartKeys "revenue" (production) key file, in one or more .lic files with a different name than your SmartKeys license file.

Edit the License File

  1. Open the Ansys license file using an ASCII editor like Notepad or vim.
  2. Edit the SERVER and VENDOR lines:
    • SERVER line:
      Replace the “hostname1” field with the host name of your license server (for a triad, replace hostname1, hostname2, and hostname3 with the host names of your three servers).
      If desired, modify the lmgrd tcp port at the end of the SERVER line; the default port is 1055.
    • VENDOR line:
      If there is a firewall, add an unused tcp port (for example, “port=1056”) to the end of the VENDOR line.
  3. If you are already serving Ansys licenses, make sure that the SERVER and VENDOR lines match in all *.lic files.
  4. Save your changes.
  5. .Start the Ansys License Manager, which will read in all the .lic files in the license_files directory.
  6. At the server end, make sure the tcp ports referenced in the license file SERVER and VENDOR lines are open for bidirectional traffic in your firewall software.

For more information on Ansys license server setup, view or download the Ansys License Management Guide at:
https://ansyshelp.ansys.com/account/secured?returnurl=/Views/Secured/prod_page.html?pn=Licensing

Ansys User Setup

Administrators or end users should modify the user environment to set ANSYSLMD_LICENSE_FILE to point to the Ansys license server in port@host syntax. For example, ANSYSLMD_LICENSE_FILE=1055@myserver

If there is a firewall between the client and the Ansys license server, the client machine firewall software must open the tcp ports for lmgrd and ansyslmd, using the ports specified in the license file running on the Ansys license server.

For more information on Ansys user licensing setup, view or download the Ansys (end user) Licensing Guide at: https://ansyshelp.ansys.com/account/secured?returnurl=/Views/Secured/prod_page.html?pn=Licensing

Frequently Asked Questions

Can you summarize the changes introduced by this migration?

  • Starting December 8, 2025, you will receive a separate license file for Ansys Semiconductor products. The license file can be downloaded from the Synopsys SolvNetPlus Download Center. You must edit the hostname information on the SERVER line of the license file before using it.
  • For other Ansys products, the license file will continue to come from the Ansys Licensing Portal. The portal will no longer include Ansys Semiconductor products.
  • The Ansys License Manager reads all .lic files in the license_files directory. Therefore, you can continue to add all license files to that directory without issues.

Do I need to update license settings or server configurations?

No. The changes are limited to the license file(s) you will receive from Synopsys and Ansys starting December 8, 2025.
