Flexible Spending Account Orders and License File Delivery

Flexible Spending Account Orders and License File Delivery

Change in FSA Redemption and Delivery for Ansys Customers

Standalone Ansys Semiconductor FSA Product Drawdowns
Ansys Semiconductor products that are part of a standalone Flexible Spending Account contract are now drawn down through the Synopsys Customer Self Service (CSS) website.

Once an FSA order is placed, license keys will be generated by the Synopsys SmartKeys system. When the updated license file is available, the CSS user will be sent an email notification that the license file is available for retrieval
(via email delivery) from the SmartKeys self-retrieval site.

Commingled Ansys Semiconductor & Non-Semiconductor FSA Product Drawdowns
For Commingled FSA with both Semiconductor and non-Semiconductor products, you will continue to drawdown using the Ansys Licensing Portal. When you generate a license, you will receive separate license files for your Semiconductor and non-Semiconductor products. Specifically:

  • Semiconductor: The request will be sent for fulfillment using the Synopsys SmartKeys system on SolvNetPlus.
    You will receive an email notification to retrieve your license file from SmartKeys, which will be delivered via email.
  • Non-Semiconductor: There is no change. The license file will be immediately delivered via the Ansys Licensing Portal.
  • Both license files must be installed on the license server in the same directory (by default, the license_files directory of the Ansys License Manager).
Synopsys and Ansys Semiconductor Flexible Spending Account Customers

Ordering: Flexible Spending Account (FSA) licensing products (keys) that are part of the FSA contract can be ordered at the Customer Self Service site at https://service.synopsys.com.

By default, only the administrator (super user) account mentioned in the contract can order FSA products through the Customer Self Service (CSS) website, but the super user can delegate the ability to other SolvNetPlus users registered for the same account (Site ID). This can be done at the CSS home page > Administration > User. Note that only super users or their designees will see the Administration tab.

Keys: Once an order is placed, keys will be generated and an email will be sent to the CSS user who placed the order that the keys are available to download the SmartKeys self-retrieval site. Then, any SolvNetPlus user registered for this Site ID can download the keys.

Software Download: The new order will enable entitlements (software download rights) for the relevant tool(s). (In some cases, it may take an hour or so for the products to be available for download.) You can view the list of all entitled tools in the SolvNetPlus Download Center.

Software may be downloaded by Electronic File Transfer from SolvNet (HTTPS) by sftp or lftp at eft.synopsys.com (after logging in with your SolvNet username and password, cd to MyProducts).

Help Demos: At the CSS home page, at the top of the screen there is a button labeled "Help Demos" to train users in the various functions. To obtain assistance on ordering licenses, click Help Demos > Tools > eLicensing. There are also demos for Reports and Administration.

Further Help: For questions on the FSA contract, contact your sales account manager.
For general questions on CSS usage, contact the CSS support team by emailing [email protected].
For assistance downloading or installing keys or software, open a Support Case in SolvNetPlus against Keys or Installation.
