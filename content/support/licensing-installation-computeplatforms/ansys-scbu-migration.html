Ansys Semiconductor Licensing Change

December 2026 Migration to Synopsys Common Licensing

What is changing

Synopsys is implementing the migration to the Synopsys Common Licensing (SCL) daemon for Ansys Semiconductor (EDA) products. SCL is a single combined vendor daemon (snpslmd) that replaces ansyslmd and other legacy Ansys license daemons. The SCL CVD solution consists of a single daemon and license file for all Synopsys and Ansys Semiconductor products.

Other Ansys products (non-Semiconductor products) are not affected by this change unless they reside on the same host as Synopsys or Ansys Semiconductor products.

Effective December 7, 2026, the license file format of Ansys Semiconductor licenses will change to the Synopsys CVD license file format that is compatible only with the Synopsys Common Licensing (SCL) snpslmd daemon. On or after this date, you will need to migrate to the SCL solution when your current keys expire, or when you re-mix, purchase, evaluate, or re-host products.

When migrating, you must replace the current Ansys license daemon (ansyslmd) used for Ansys Semiconductor products with the Synopsys Common Licensing snpslmd daemon, version 2026.12 or later.

Even though the license file format will change to the Synopsys SCL CVD format, there are no changes to the licensing Bill of Features; your licensed product numbers and feature names will remain the same.

There is no required update to new tool versions as there are no licensing-related changes to the Ansys Semiconductor tools themselves; only the license server daemon and license file format will change.

How to obtain new SCL CVD licensing components on or after Dec 07, 2026:
  • Retrieve the CVD-format license key file from Synopsys SmartKeys: https://www.synopsys.com/SmartKeys
  • Download the Synopsys Common Licensing daemon from the SolvNet Download Center: https://solvnet.synopsys.com/DownloadCenter
    • For Windows, download ony the scl_v2026.12.exe file.
    • For Linux, download the scl "common.spf" and "os_platform.spf" files. For example, scl_v2026.12_common.spf and scl_v2026.12_linux64.spf. Also download the Synopsys Installer, which is required to install SCL on Linux platforms. Synopsys Installer is listed as a separate product in the Download Center.
    • For installation assistance, see https://www.synopsys.com/scl
Important configuration and deployment information:
  • Migration timeline: On or after December 7, 2026, you must migrate when your current keys expire, or when you re-mix, purchase, evaluate, or re-host Ansys Semiconductor products. Synopsys Common Licensing version 2026.12 (updated lmgrd and snpslmd) will be required for the migration.
  • License file compatibility: SCL 2026.12 will not start if ansyslmd or another legacy Ansys daemon is running. Therefore, you must shut down any legacy Ansys daemon (ansyslmd, apacheda, hclmd, ansoftd) before starting SCL 2026.12 on the same machine.
  • License file hostname: The Ansys Semiconductor license key file delivered from Synopsys will not contain the hostname. You must manually edit the license file, locate the SERVER line, and replace the "hostname1" field with the correct hostname, or the license server will not start.
  • License file VENDOR line: The VENDOR or DAEMON line must refer only to snpslmd. If you enter the path to snpslmd (VENDOR snpslmd /path/to/snpslmd), make sure the path points only to the new 2026.12 snpslmd daemon version.
  • Mixed Ansys environments: If you have license keys for other Ansys products (non-Semiconductor products) on the same host, install the Synopsys CVD-format license file and the Ansys-format non-Semiconductor license file in the same directory. (The file extensions should be *.lic.) Make sure no VENDOR or DAEMON line points to ansyslmd or other Ansys daemon. Then point lmgrd to the directory name. For example, where "/opt/snps/scl" is the SCL 2026.12 directory:
    /opt/snps/scl/linux64/lmgrd -c /opt/snps/scl/license_dir -l /opt/snps/scl/logs/synopsys.log Alternatively, you can combine the license files and start the combined file with Synopsys SCL (lmgrd and snpslmd). If you combine the license files, make sure to remove duplicate SERVER, VENDOR, DAEMON, or USE_SERVER lines. Then start SCL by pointing lmgrd to the license file name. For example,
    /opt/snps/scl/linux64/lmgrd -c /opt/snps/scl/license_dir/synopsys.lic -l /opt/snps/logs/synopsys.log

Beta Testing

Customers that wish to participate in beta testing may do so by contacting their Synopsys Sales Account Manager.

To test SCL 2026.12 beta, you must provide your account manager with a hostid. It is suggested that you use a separate machine not hosting Synopsys or Ansys production licenses for the evaluation. The Account Manager will generate test keys for the new hostid. Once you have the test keys, you may obtain technical support by opening a SolvNet Support Case against "SCL-Synopsys Common Licensing."

Participation in the beta testing is optional. Customers that do not participate in the beta should still plan for the licensing migration described in this communication.

Frequently Asked Questions

1. What is changing?

Ansys Semiconductor (EDA) product licensing is moving to Synopsys Common Licensing. The legacy Ansys daemons for Ansys Semiconductor products are being replaced by the Synopsys snpslmd daemon, and license files are moving to the Synopsys combined vendor daemon format.

2. When do I need to migrate?

On or after December 7, 2026, move to the SCL 2026.12 snpslmd license server when your current keys expire, or when you re-mix, purchase, evaluate, or re-host products and retrieve a new key file.

3. Where do I download the new SCL license server?

Download SCL 2026.12 and the Synopsys Installer from the SolvNet Download Center at https://solvnet.synopsys.com/DownloadCenter.

4. Where do I get the SCL CVD-format license keys?

On or after December 7, 2026, retrieve the CVD-format key file from Synopsys SmartKeys at https://www.synopsys.com/SmartKeys. Before this date, beta participants must work with their Synopsys Account Manager so that Synopsys can generate the beta test keys using the submitted host information.

5. Can I run ansyslmd and snpslmd on the same machine?

No. The Ansys ansyslmd daemon and the Synopsys CVD snpslmd daemon cannot run on the same machine. If you must keep older licenses running, host them on a separate machine.

6. Is my existing license file compatible after switching?

The legacy-format Ansys license key file can be used with the SCL license server, but it must not be merged with later Ansys keys in the new CVD license-file format. (CVD keys will have "AUTH=" fields that refer to both snpslmd and to ansyslmd or other legacy Ansys daemon.)

7. What if I also use other Ansys products that are not Semiconductor products?

If those license keys are on the same host, combine your Synopsys and Ansys license files and use the combined file with Synopsys SCL version 2026.12 (lmgrd and snpslmd).

8. What should I check if the license server does not start?

  • Shut down all Ansys license daemons on the machine before starting the SCL license server.
  • Make sure that you are using the latest lmgrd and snpslmd provided with SCL 2026.12 (FlexNet version 11.19.10).
  • (For combined Ansys/Synopsys license files), make sure to remove duplicate SERVER, VENDOR, DAEMON, or USE_SERVER lines.
  • On the SERVER line of the license file,
    • Modify the hostname1 field to specify the correct hostname.
    • Verify that the hostid field (usually the 12-character MAC address) is correct.
      (The hostid is encrypted into each key and cannot be modified.)
  • On the VENDOR or DAEMON line,
    • Make sure only the snpslmd daemon is specified.
    • Enter the full path to snpslmd (VENDOR snpslmd /path/to/snpslmd).

9. Do I need to change or reinstall my products?

No. There are no changes to the Semiconductor products themselves. The new solution will support both new and older Ansys products. Only the license server and license key file format are changing.

10. How will I be reminded before go-live?

You will receive communications two months, one month, and seven days before the December 7, 2026 release.
