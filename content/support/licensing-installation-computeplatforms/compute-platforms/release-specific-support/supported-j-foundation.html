style
main

This guide lists the platforms supported by the Synopsys J-Foundation Releases 2014.06, 2014.09, 2014.12. A platform consists of the computer architecture and the operating system version. Not all Synopsys products are available on every platform listed below. For an exact listing of platform availability for Synopsys products you have purchased, consult the Synopsys Solvnet Download Center at https://solvnet.synopsys.com/DownloadCenter/dc/product.jsp

Use the following index to jump directly to the J-Foundation Operating System and Patch recommendations:

x86 (IA-32) Linux 32-bit
x86_64 Linux 64-bit
x86 Microsoft Windows
x86_64 Solaris 32-bit & 64-bit
SPARC Solaris 32-bit & 64-bit
IBM RS6000 AIX 32-bit & 64-bit

Synopsys tests and supports specific versions of each operating system. These are the operating system versions that Synopsys performs extensive testing on and fully support. Operating system vendors guarantee that applications compiled on a lower minor version of an operating system will be binary compatible with higher minor versions of the same operating system. This means that an application supported on OS version X.Y should run on OS version X.Y+Z. For example, a program supported on RHEL 5.0 should run on RHEL 5.4. While Synopsys can only guarantee the versions we support, customers can rely on the OS vendor's claim when running higher minor versions. OS vendor claims may not apply across major versions; therefore a program that supports RHEL 5.0 may not be compatible with RHEL 6.0 unless directly specified.
