OS Platform End-of-Life – Itanium

OS Platform End-of-Life – Itanium

Dear Synopsys Customer:

NOTE: The information in this letter affects only those customers using the Itanium processor. If this does not apply to you, please disregard.

This letter is to inform you that Synopsys is announcing its program for the end-of-life of support for the Itanium processor. Synopsys will not produce any new feature releases for systems using the Itanium processor after the 2007.06 software release. Synopsys will continue to support service packs and critical bug fixes for this last feature release on the Itanium processor until June 2008.

MORE ABOUT SYNOPSYS COMPUTE PLATFORMS:

Information on the processor architectures, operating systems and versions supported by Synopsys products is available at the Synopsys web site here.

If you have any questions, please contact either your local support team or your Synopsys sales representative.
