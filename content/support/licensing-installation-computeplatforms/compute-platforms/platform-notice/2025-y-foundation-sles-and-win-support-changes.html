Important Notice: OS Platform Support Changes

NOTE: This notice affects only customers using SUSE Linux Enterprise Server or Microsoft Windows operating systems. If this does not apply to you, please disregard.

Dear Synopsys Customer:

Synopsys believes our customers need stable, well-supported operating systems on which to run their EDA tools. For Synopsys to align our support with the timelines of our OS and hardware vendors, we are updating the Synopsys Compute Platforms Roadmap.

Starting with the 2026.03 (Y-Foundation) software release:

  • For SUSE SLES, the minimum supported OS version will be SLES 15-SP3.
    • SLES 12+ and SLES 15-SP2 will no longer be supported.
  • For Windows OS, the minimum supported Server version will be 2022.
    • Windows 10 will no longer be supported
    • Windows Server 2019 will no longer be supported.
    • Windows Server 2022 becomes the baseline release.

The X-Foundation releases (2025.06, 2025.09, 2025.12) will be the final feature releases to support:

  • SLES12-SP5+, SLES15-SP2
  • Windows Server 2019
  • Windows 10

For a list of supported platforms and OS versions, see the Platforms Roadmap at https://www.synopsys.com/support/licensing-installation-computeplatforms/compute-platforms/compute-platforms-roadmap.html

The above changes do not change the support for prior software releases. For OS platform support information on feature releases prior to 2026.03, and their Service Packs, see https://www.synopsys.com/qsc

If you have any questions, open a Support case at https://solvnetplus.synopsys.com and specify "Installation" as the product. Alternately, contact your local support team.

Thank you,

Synopsys Platform Support team
