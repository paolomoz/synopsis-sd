Important Notice: OS Platform Support Changes

NOTE: This notice affects only customers using CentOS Linux operatingsystems. If this does not apply to you, please disregard.

Dear Synopsys Customer:

We believe our customers need stable, well-supported operating systems on which to run their EDA tools. For Synopsys to align our support with the timelines of our OS and hardware vendors, we are updating the Synopsys Compute Platforms Roadmap.

This is to inform you, that starting with the 2022.03 (T-Foundation) software release:

  • CentOS 8.x will no longer be supported.

The S-Foundation releases (2021.06, 2021.09, 2021.12) will be the final feature releases
to support CentOS 8+. Please note that CentOS 7.3+ will continue to be supported.

For the T-Foundation, other OS platforms will continue to be supported. For a list of supported platforms and OS versions, see the Supported Platforms Guide at https://www.synopsys.com/qsc

These changes do not change the support for prior software releases. For OS platform support information on feature releases prior to 2022.03, and their Service Packs, see https://www.synopsys.com/qsc

More about Synopsys Compute Platforms:
Roadmap information on supported hardware platforms, operating systems, and OS versions is available at the Synopsys website at: https://www.synopsys.com/support/licensing-installation-computeplatforms/compute-platforms/compute-platforms-roadmap.html

If you have any questions, open a Support case at https://solvnetplus.synopsys.com and specify "Installation" as the product. Alternately, contact your local support team.

Thank you,

Synopsys Platform Support team
