April 2011

Dear Synopsys Customer:

NOTE: The information in this notice only affects those customers that have developed their own tools that directly link to the libCstd library in our Solaris products. If this does not apply to you, please disregard.

We believe our customers need stable, well-supported tools on which to run their EDA tools. The following changes are being made in order to allow us to provide a better supported products.

Effective March 2012,Synopsys is replacing the libCstd C++ library with the libstlport C++ library. This change is being made because libstlport has better support from the OS vendor and conforms more closely to the standard.

This change will not affect the way the tool operates. Users who do not have self developed tools that directly interfaces with Synopsys software on the Solaris platform will not be affected. Users that develop tools that directly interface with Synopsys products need to use libstlport4 library instead of libCstd.

Please contact your local Synopsys support center if you have any questions or need assistance.

Thank you for your continued interest in Synopsys.

Sincerely,
Synopsys, Inc.
