A-Foundation 2007.09 Red Hat Enterprise Linux Baseline Changes

A-Foundation 2007.09 Red Hat Enterprise Linux Baseline Changes

Dear Synopsys Customer:

NOTE:The information in this letter affects only those customers using the Red Hat Enterprise Linux (RHEL) Operating System (OS). If this does not apply to you, please disregard.

We believe our customers need stable, well-supported operating systems on which to run their EDA tools. In order for us to align to timelines of our OS and hardware vendors, we are updating our compute platforms roadmap.

This letter is to inform you that Synopsys is migrating the baseline version of Red Hat Enterprise Linux that we support to RHEL v4 as of the 2007.09 product feature releases.

This means we will build and test our products for this release and subsequent A-Foundation releases on RHEL v4, and test RHEL v5 as a binary compatible OS. RHEL v3 will no longer be supported on feature releases starting with 2007.09.

Service packs to releases prior to 2007.09 will continue to support the foundation of the corresponding feature release. These service packs will continue to support RHEL v3.

NOTE: Given the current release schedule, most Galaxy™ Design Platform and Discovery™ Verification Platform feature releases will release on the A-Foundation in 2007.12. HSPICE® simulator is the only Galaxy™ Design Platform and Discovery™ Verification Platform tool currently scheduled to have a feature release in 2007.09.

More about Synopsys Compute Platforms:
Information on supported hardware platforms, operating systems, OS versions, and patch bundles for Synopsys products is available at the Synopsys web site here.

If you have any questions, please contact the Synopsys Support Center or your local sales support team.
