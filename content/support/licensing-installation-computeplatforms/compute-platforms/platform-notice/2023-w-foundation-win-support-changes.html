Windows OS Support Changes for W-Foundation Releases (2024.09, 2024.12, 2025.03)

Important Notice: OS Platform Support Changes

NOTE: This notice affects only customers using Microsoft Windows operating systems. If this does not apply to you, please disregard.

Dear Synopsys Customer:

Synopsys believes our customers need stable, well-supported operating systems on which to run their EDA tools. For Synopsys to align our support with the timelines of our OS and hardware vendors, we are updating the Synopsys Compute Platforms Roadmap.

Starting with the 2024.09 (W-Foundation) software release:

  • For Windows OS, the minimum supported Server version will be 2019.
    • Windows Server 2016 will no longer be supported.
    • Windows Server 2019 becomes the baseline release.

The V-Foundation releases (2023.09, 2023.12, 2024.03, 2024.06) will be the final feature releases to support:

  • Windows Server 2016

For a list of supported platforms and OS versions, see the Platforms Roadmap at https://www.synopsys.com/support/licensing-installation-computeplatforms/compute-platforms/compute-platforms-roadmap.html

The above changes do not change the support for prior software releases. For OS platform support information on feature releases prior to 2024.09, and their Service Packs, see https://www.synopsys.com/qsc

If you have any questions, open a Support case at https://solvnetplus.synopsys.com and specify "Installation" as the product. Alternatively, contact your local support team.

Thank you,

Synopsys Platform Support team
