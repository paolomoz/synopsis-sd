Advanced Usage of Synopsys Virtualizer in Pre-silicon SW Development

Synopsys Virtualizer Development Kits (VDKs) have been used for pre-silicon software development of NVIDIA Tegra chips for several generations. Specifically, VDKs have been traditionally used for basic boot and functional verification. However, there are other advanced use cases of VDKs that are typically not utilized.

This session will cover these advanced software use cases including hybrid VDKs and FPGAs, standalone Functional Safety Island VDKs, fault injection, fuse burning, and recovery boot.
