Driven by the trend towards software-defined vehicles (SDV), more complex software stacks are now being integrated into innovative automotive E/E architectures. Today the early integration testing of automotive software is already supported by using virtual ECUs (vECUs). This webinar, presented with Elektrobit, will discuss why electronics Digital Twins are necessary in automotive software development. It will discuss Level-3 vECU use cases and describe the workflow to create L3 vECUs, including a demonstration.

​

Summary:

This 30-minute webinar will explore how Level 3 vECUs enable comprehensive testing for AUTOSAR Classic Platform (CP).

​

Key topics and takeaways:

  • The benefits of using vECUs for cost savings, faster turn-around time, and better debug capabilities
  • How to simplify the process of configuring and generating Level-3 vECUs with EB tresos Studio and Synopsys Silver
  • Live demonstrations for a hands-on understanding of how to use the EB tresos Studio and Synopsys Silver to optimize BSW testing in AUTOSAR development projects
