How to Migrate an Analog Design Like a Pro

Webinar Summary
Migrating analog designs across process nodes is often a complex and time-consuming challenge for engineering teams. In this webinar, Credo will share its experience using Synopsys ASO.ai—part of the Synopsys.ai™ EDA suite—to streamline and accelerate the migration of analog circuits between process nodes. The session will highlight how automated schematic migration and built-in optimization features can simplify and improve the migration process.

What You’ll Learn

  • How Synopsys ASO.ai automates the transfer of schematics between process nodes, reducing manual effort and errors.
  • The role of the built-in optimizer in efficiently determining optimal device parameter values based on your design’s target metrics.
  • Real-world insights from Credo’s migration of an analog design from a 5nm node to a 7nm node using ASO.ai.

Key Takeaways

  • Automated schematic migration features in Synopsys ASO.ai can significantly simplify and speed up the design migration process.
  • The optimizer tool helps achieve target design metrics by determining optimal device parameters.
  • Credo’s successful migration demonstrates the capabilities and tangible benefits of using ASO.ai for analog design migration.

Who Should Attend
Analog design engineers, circuit design engineers, analog design managers, CAD engineer, layout engineers, EDA tool users, and anyone interested in improving efficiency and outcomes in design migration projects.
