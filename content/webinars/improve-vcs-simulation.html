Advanced Technologies to Improve VCS Simulation Performance

Synopsys Webinar | On-Demand

This Synopsys webinar discusses how to achieve the best performance with the Synopsys VCS functional verification solution. We will present new Synopsys VCS innovations that help to further increase simulation performance up to 10x such as Synopsys VCS' Dynamic Test Loading (DTL). We'll specifically review how DTL enables the loading of tests dynamically at runtime, resulting in significant savings in compile and run times.
