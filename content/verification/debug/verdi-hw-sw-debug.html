Verdi HW/SW Debug

Datasheet

Instruction-Accurate Embedded Processor Debug With Synchronized RTL, C, Assembly Visibility

Embedded software plays a critical role in driving today’s SoC verification at various stages. With growing SoC complexity and evolving processor architecture, it has become increasingly difficult to perform SoC debug activities. What is needed is a simultaneous view of both hardware and software to help designers efficiently and effectively advance their debug productivity.

Synopsys’ Verdi® HW SW Debug enables embedded software-driven SoC verification by providing a synchronized multi-window view of the design’s behavior of both hardware and software. It combines an instruction accurate embedded processor, RTL, C and assembly visibility for a comprehensive SoC debug solution.
