IAV: Virtual Transmissions for Faster Control Development

style
pt-sm

The leading German engineering service provider IAV has integrated Silver and TestWeaver into its TCU development process in order to:

  • virtually integrate and test the control software on Windows PCs
  • measure and pre-calibrate the virtual transmission with CANape and INCA
  • simulate CAN network communication
  • test and validate the software and debug using Microsoft Visual Studio.
