Tools & Embedded Software Partners

Elektrobit

Elektrobit and Synopsys deliver a pre‑silicon AUTOSAR environment enabling early integration with L3 virtual ECUs generated from Elektrobit’s production middleware, while porting Elektrobit’s AUTOSAR Classic stack onto Synopsys VDK‑based virtual SoCs to accelerate shift‑left development.

Learn More

eSol

Synopsys collaborates with eSol to deliver Synopsys VDKs for eSol's eMCOS, their scalable real-time operating system to run on leading automotive MCUs/SoC.

Learn More

Green Hills Software

Synopsys collaborates with Green Hills Software leveraging the full portfolio of Green Hills safety-certified RTOSs, hypervisors, C/C++ compilers, and advanced multi-core, OS-agnostic development tools on Synopsys’ comprehensive VDK platform family.

HighTec

IPG Automotive

IPG Automotive and Synopsys jointly deliver an integrated SDV virtualization solution combining CarMaker’s high‑fidelity vehicle dynamic and environment simulation with Synopsys virtualization solution, enabling a multi‑fidelity and multi‑ECU virtual prototype for full‑stack SDV development.

Lauterbach

MathWorks

MathWorks leverages the Synopsys Virtualizer/VDK to execute Simulink models within a vHIL environment. MathWorks Hardware Support Package for Infineon AURIX explicitly incorporates VDK, enabling code execution and model testing in virtual hardware target. MathWorks and Synopsys enable a closed‑loop workflow that enables testing and validation of production‑intent ECU software on Synopsys‑based virtual ECUs directly with Simulink models which speed up V&V workflows, empowering customers to validate software earlier.

Learn More

Stradvision

Synopsys collaborates with STRADVISION to deliver Synopsys VDKs for the TI TDA5 SoC family, enabling Stradvision to deliver pre‑integrated SVNet FrontVision and SurroundVision software with those VDKs.

Vector

Synopsys and Vector are collaborating on next generation development and validation capabilities—combining electronics digital twin and software factory solutions—to significantly accelerate automotive software development. This includes advancing the open-source library SIL Kit, as well as integrating Silver and VDKs with MICROSAR and CANoe to provide ready-to-use vECUs for all types of ECUs within an SDV architecture. The partnership further enables companies across the automotive ecosystem to collaboratively design, build, and verify complex subsystems using integrated capabilities from both organizations.
