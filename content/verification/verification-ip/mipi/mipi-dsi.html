Architecture and Key Features

Architecture and Key Features

Specifications

  • DSI-2 v2.0,1.1, DSEv1.1
  • DPHY 3.0, 2.5, 2.1
  • CPHY 2.1, 2.0

DUT Types/Topology: Host and Device

Key VIP Features

  • Dual DSI, DSI Host, DSI Device, four virtual channels
  • Specification linked Functional coverages
  • Scoreboard, callbacks and error injection

Debug and Analysis

  • Verdi based protocol and performance analysis
  • Protocol checks at each layer
  • Debug ports and trace files
  • Transaction log, Verbosity Messages

Key Protocol Features

  • Protocol Layer:
    • DCS command, generic commands and Video Mode
    • Short and Long packet structures, multiple high Speed (HS) packets per transmission
    • Video transmission in burst and non-burst modes
    • 16/18/24/30/36 RGB pixel formats in video mode
    • Normal as well as interleaved data streams
    • ECC generation, checksum (CRC) generation and checking, error detection and reporting
    • DSC compression and decompression
    • Scrambling mode command
    • SEP, PENP Data types, packed pixel stream-20bit
  • Physical Layer:
    • D-PHY & C-PHY Serial and Parallel (PPI) Interface
    • One to four PHY data lanes and one clock lane
    • High Speed Transmission in D-PHY and C-PHY
    • Escape Mode Support in D-PHY and C-PHY

Test Suites / Groups Features

  • Supports DUT as DSI Device Controller
  • Tests targeting Protocol layer and Physical layer
