Architecture and Key Features

Specifications

  • IEEE 802.3 Clause 24 (100 Base-X), Clause 28 (Auto-Negotiation on twisted pair), Clause 40 (1000BASE-T), Clause 96 (100BASET1), Clause 97 (1000BASET1), Clause 98 (Single twisted-pair Auto-Negotiation), Clause 125,126 (2.5/5G BASE-T), cg Clause 147 (10BASE-T1S), Clause 148 (PLCA)
  • OPEN Alliance 10BASE-T1S Transceiver

DUT Types/Topology: MAC to MAC, MAC+PHY(serial/parallel) to MAC+PCS (serial/parallel)

Key VIP Features

  • Flexibility to enable / disable Scrambler
  • VIP to be programmed in Master/Slave mode
  • Flexibility to enable / disable initial noise insertion

Debug and Analysis

  • Verdi based protocol and performance analysis
  • Protocol checks at each layer
  • Debug ports and trace files
  • View all Ethernet Frames at the MAC Layer
  • Browse multiple transactions in sync with wave and log views
  • Extensive filtering to speed debug

Key Protocol Features

  • Flexibility to enable / disable Scrambler
  • Programmable RS FEC Error Correction, Scrambler Seed value
  • Programmable match/mismatch count for assertion/ de-assertion of scr_status, loc_rcvr_status, rem_rcvr_status etc
  • Feature set for 10BaseT1S
  • User programmable 10BaseT1S Timers.
  • Variable jitter support
  • User programmable Base T1 Timers [For example: LPI / Stabilize / AN /Link Sync etc timers]
  • Programmable Info Field register values

Test Suites / Groups Features

  • Transition of Link Sync /TX /RX State Machine
  • Info Field encoding and decoding
  • 80b/81b , 4b/3b Encoding /Decoding, RS- Decoder
  • 3b2T Data manipulation
  • EEE / OAM Verifying tests
  • Test Pattern Modes
