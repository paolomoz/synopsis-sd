Key Protocol Features

  • Protocol Layer Features
    • All transfer types (Ctrl, Bulk, intr, Iso & Split transfers)
    • High bandwidth Iso/Interrupt transfers, Interleaving transfers/Ping transfers
    • Different handshaking response (NAK/NYET/STALL/Nohandshake(timeout))
    • Device framework transfer initiation
    • PL Exceptions and error injections in packets (CRC16/5 error/Invalid PID/NPID/packet field errors, timeout)
  • Link Layer Features
    • All state machines entry/exit, Power mgmt. state entry/exit(L1/L2)
    • Vbus cut off in-between transfers & during suspend
    • Disconnect/connect during transfers & during reset, protocol reset in-between transfers
    • Fslsserialmode/Test mode support
    • OTG-SRP/HNP/ADP
  • PHY Features
    • Physical Exception and error injections(invalid SYNC and EOP, Bit-stuff error, Rxerror scenarios etc…)
    • Sync/EOP length adjustment, Preamble mode support
    • Keep alive(HS/LS) support

Test Suites / Groups Features

  • Host/Device/HUB/PHY/XHCI
  • AHB/AXI bus interface support along with system memory and backdoor
  • Multi-controller and Multi-port support
  • Tailor Made for Testbench Migration from IP level to SoC level
