Get Started

Synopsys Verification IP (VIP) for eMMC also supports SD host and card and provides a comprehensive set of protocol, methodology, verification and productivity features, enabling users to achieve rapid verification of SD based designs.

anchor
overview

Protocol Features

  • Supports SD Physical Layer Specification 4.2
  • Host and Card model
  • All data widths (1 and 4 bit)
  • All transfer modes (single and multiple blocks)
  • All protection mechanisms
  • Lock/Unlock support
  • Memory density support (Standard ,High, Extended Capacity)
  • Support byte and Block Mode Operation
