Architecture and Key Features

Specifications: CXS D,CXS C(Lite), B, A​

DUT Types/Topology: VIP can be configured as TX only, RX only, or both​

Key VIP Features

  • Configurable number of CXS TX RX Agents under SVT CXS Env​
  • Callback, functional coverage and protocol checks​
  • Error injection support for specific scenarios​
  • Delay support on CXS interface signals ​
  • Supports both active and passive modes

Debug and Analysis

  • Debug signals at VIP interface ​
  • Protocol checks in active and passive mode​
  • Verbosity controlled log file

Key Protocol Features

  • Support for CXS Flow Control ​
  • CXS Link Activation Deactivation Support​
  • Support for all CXSDATAFLITWIDTH and CXSMAXPKTPERFLIT configurations ​
  • Supports different max credits for Rx and Tx paths of the VIP​
  • Deactivate hint Support ​
  • Support larger packets spanning multiple flits​
  • Support for continues data mode​
  • Support for odd byte parity
