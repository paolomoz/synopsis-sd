Architecture and Key Features

Specifications:

  • eDP 2.0/1.5a/1.4b, HDCP 2.2/1.3, DSC 1.2a
  • Video timing CEA-861-F, DMT v1r13, CVT v1.2

DUT Types/Topology: Source and Sink

Key VIP Features:

  • Specification linked Functional coverages & verification plans
  • Callbacks for Source, Sink drivers and monitors.
  • Error injections using exceptions
  • Transaction level Higher Abstraction APIs for Audio/Video/Control transaction

Debug and Analysis:

  • Verdi based protocol and performance analysis
  • Protocol checks at each layer
  • Debug ports for all FSM and monitored data
  • Stream layer, main link layer and aux layer debug ports
  • Trace Files for Video/Audio/SDP/Symbol & Verbose logfiles
  • Ability to read video/audio data from file

Key Protocol Features:

  • Aux less ALPM support for both serial & 10-bit parallel interface with or without PR
  • Panel Replay for both serial and 10-bit parallel interface
  • Panel Replay in 128b/132b MST mode
  • Adaptive Sync updated as per latest SCR
  • Adaptive Refresh Panel (ARP)
  • AUX wake ALPM supported for PSR and PSR2
  • Support for DSC with PR and PSR2 (line granularity)
  • 3D, 8K/10K frames and custom frame support

Test Suites / Groups Features:

  • Source-code pre-defined testcases with UVM Testbench
  • Easily integrated with DP Source/Sink/LTTPR DUT and USB4 Tunneling topologies into ready to use environment components
  • USB4 tunneling support with and without Router for both DP2.1(EA) and DP1.4
  • Audio/Video/Control transaction. In built sequences along with testcases for every protocol version
