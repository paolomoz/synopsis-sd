About VC SpyGlass Fault Analysis

style
pt-md, centered
anchor
overview

Synopsys VC SpyGlass Fault Analysis performs functional safety analysis early in the design flow to provide guidance for design changes resulting in ISO 26262 functional safety metric improvements. This technology also enables soft error analysis for identification of most vulnerable design hotspots to guide impactful design changes for reliability improvement. Leveraging Synopsys SpyGlass technology, analysis can be performed either in RTL or gate-level netlists, minimizing impact to design schedules.
