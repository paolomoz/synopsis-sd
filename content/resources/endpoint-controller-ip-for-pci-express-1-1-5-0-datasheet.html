Synopsys Endpoint Controller IP for PCI Express (1.1 - 5.0) Datasheet

Download the Synopsys PCIe Endpoint Controller IP datasheet and see how a fully synthesizable, parameter-rich core enables rapid integration across 1–16 lanes, with advanced security, SR-IOV, and robust debug for PCIe 5.0/4.0/3.1/2.1/1.1.

What You Will Learn:

  • How to configure datapath width, PIPE interface, and AMBA AXI/native application ports for optimal performance and area
  • Methods for TDISP/IDE security integration, ECC/parity protection, and ISO 26262 ASIL-B certification for automotive/HPC
  • Support for up to 32 physical functions, 256/64K virtual functions (SR-IOV/ARI), and 8 traffic classes with virtual channel mapping
