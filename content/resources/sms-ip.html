Synopsys SMS IP: Complete Memory Test, Repair and Diagnostics Solution

The Synopsys SMS IP solution is a comprehensive, integrated test, repair and diagnostics solution that supports repairable or nonrepairable embedded memories across any foundry, process node or memory IP vendor. Silicon-proven in over a billion chips on a range of process nodes, the Synopsys SMS IP is a cost-effective solution for improving test quality and repair of manufacturing faults found in advanced technologies like FinFET.
