Synopsys Enterprise Ethernet MAC Controller IP Datasheet

The Synopsys Enterprise Ethernet MAC (XLGMAC) datasheet details a high-throughput, area-optimized RTL core—supporting GMII/XGMII/XLGMII, advanced flow control, and offload for IPv4/IPv6, TCP, UDP, and ICMP.

What You Will Learn:

  • How to select XLGMAC-CORE, XLGMAC-MTL, or XLGMAC-AXI for native, transaction-layer, or AXI subsystem integration
  • Protocol support: IEEE 802.3 (1G–100G), 802.3az (EEE), 802.1Q (VLAN), 1588 (PTP), 802.1AS/Qav (AVB), and more
  • MAC features: programmable address filtering, jumbo/truncated frames, VLAN stacking, and per-frame control
