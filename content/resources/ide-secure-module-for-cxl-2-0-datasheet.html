Synopsys IDE Secure Module for CXL 2.0 Datasheet

Download the Synopsys CXL 2.0 IDE Security IP Module datasheet and see how a plug-and-play, AES-GCM-based solution delivers confidentiality, integrity, and replay protection for FLITs and TLPs.

What You Will Learn:

  • How to deploy high-throughput, full-duplex encryption/authentication for CXL.cache/mem (FLITs) and CXL.io (TLPs)
  • Flexible configuration: 512-bit bus, x8/x16 lanes, multi-stream, and protocol selection for .cache/.mem/.io
  • Security features: AES-GCM crypto, PCRC/ECC, in-flight key refresh, containment/skid modes, and bypass
