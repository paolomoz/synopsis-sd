Synopsys Inline Memory Encryption (IME) Security Modules Datasheet

Synopsys Inline Memory Encryption (IME) Security Modules provide confidentiality of data in use or stored in off-chip memory over memory interfaces. They integrate seamlessly with Synopsys DDR, LPDDR, and MRDIMM IP Controllers for most optimal solutions in the industry with latency as low as 2 cycles, accelerating SoC integration and reducing risk.

What You Will Learn:

  • Discover scaling encryption for any memory bandwidth or region
  • Learn how robust key freshness monitoring and secure key readback are implemented
  • See how to achieve ultra-low latency integration with Synopsys DDR controllers
