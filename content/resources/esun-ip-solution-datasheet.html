Ethernet for Scale-Up Networking (ESUN) IP Solution

The Synopsys ESUN IP solution is the industry's first complete Layer 1 and Layer 2 IP offering purpose-built for Ethernet-based AI scale-up networks. Compliant with the OCP ESUN v1.0 specification, the solution integrates a 1.6T multi-rate Ethernet MAC, PCS with RS-FEC, a dedicated UEC/ESUN Link Layer Controller with Link-Level Retry and Credit-Based Flow Control, silicon-proven 224G Ethernet PHY, and ESUN-ready verification IP with SoC Verification Kit. Download the datasheet to explore the full architecture, features, and supported configurations.

  • Complete L1+L2 IP stack in one datasheet — Get full technical details on the integrated MAC, PCS, UEC/ESUN Link Layer Controller, and silicon-proven 224G PHY, purpose-built for OCP ESUN v1.0 compliant AI scale-up fabrics
  • Lossless reliability and congestion management — Understand how Link-Level Retry (LLR) eliminates costly higher-layer retransmissions and Credit-Based Flow Control (CBFC) delivers fine-grained, per-virtual-channel lossless operation
  • Flexible multi-rate configurations — Review supported interconnect rates from 1.6T down to 100G across 224G and 112G SerDes, with scalable 1-, 2-, and 4-port architectures for diverse AI/HPC system requirements
  • Pre-verified for first-pass silicon success — Learn how the co-designed IP stack, ESUN-ready SoC Verification Kit (SVK), and Synopsys' signal/power integrity analysis minimize integration risk and accelerate time-to-market
