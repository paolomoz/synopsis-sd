Synopsys AMBA Advanced I2C/SMBus Controller and Target Device IP Datasheet

Download the Synopsys Advanced I2C/SMBus Controller and Target Device IP datasheet and see how a fully programmable, APB-integrated core enables robust, multi-speed bus operation—optimized for NVMe, PMBus, and datacenter use cases.
