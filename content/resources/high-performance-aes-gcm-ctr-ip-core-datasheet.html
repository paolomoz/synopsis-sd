Synopsys High-Performance AES-GCM/CTR IP Core Datasheet

Download the Synopsys Pipelined AES-GCM/CTR Core datasheet and see how a compact, flow-through architecture delivers 100+ Gbps throughput, context interleaving, and low-latency AES-GCM/CTR encryption—fully NIST SP800-38D compliant.

What You Will Learn:

  • How to configure for 64–128 bits/cycle (up to 102 Gbps @ 800 MHz) and 128/192/256-bit keys
  • Flow-through, pipelined design: supports context interleaving, stall mitigation, and high-speed switching
  • GCM, GMAC, and AES-CTR modes with internal hash key generation and 96-bit IV support
