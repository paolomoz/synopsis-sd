Model-Based Design and Virtual ECUs Enable Early Testing for Electric Vehicle Controls

The transition to Software Defined Vehicles (SDVs) demands advanced system-on-chips (SoCs) with specialized hardware for complex functions. Model-Based Design (MBD) and Virtual Electronic Control Units (vECUs) enable efficient algorithm transition and early testing. This whitepaper covers the development of a Field-Oriented Control (FOC)-based motor control system using Infineon® AURIX™ TC4x architecture and Synopsys Virtualizer™ tooling, highlighting power optimization in Li-ion motors, AI-based position estimation, and hardware-optimized code generation.

Key Takeaways:

  • Advanced SoCs for SDVs: Specialized hardware for complex functions.
  • Model-Based Design (MBD): Efficient algorithm transition for high-performance code.
  • Virtual ECUs (vECUs): Early testing and enhanced debugging.
  • FOC Algorithm & AI: Power optimization and position estimation for Li-ion motors.
