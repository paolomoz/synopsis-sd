Synopsys Secure Boot Software Development Kit Datasheet

Download the Synopsys Secure Boot SDK datasheet and see how a flexible, ISO C toolkit enables cryptographic code authentication and decryption—supporting SHA-256, AES-CCM/CTR, RSA, and EC-DSA, with hardware offload options for fast, secure system boot.

What You Will Learn:

  • Loader options: ultra-small (SHA-256 only), signature/encrypted (RSA/EC-DSA + AES-CTR), or compact encrypted (AES-CCM)
  • NIST CAVP-validated cryptographic algorithms: AES-CCM/CTR, SHA-256, RSA PKCS#1, and X9.62 EC-DSA
  • Portable, tiny ISO C source (<5–20KB), with adaptable Phase0a/0b/0c boot methods for any platform size
