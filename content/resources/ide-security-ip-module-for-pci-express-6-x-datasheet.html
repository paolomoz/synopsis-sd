Synopsys IDE Security IP Module for PCI Express 6.x Datasheet

The Synopsys Integrity and Data Encryption (IDE) Security IP Module for PCIe 6.x provides confidentiality, integrity, and replay protection against hardware-level attacks. IDE adds optional capabilities for PCIe devices to perform hardware encryption and integrity checking on packets transferred across PCIe links.
