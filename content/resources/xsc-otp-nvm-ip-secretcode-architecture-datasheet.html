Synopsys XSC OTP NVM IP SecretCode Architecture Datasheet

Download the Synopsys XSC OTP NVM IP datasheet and see how SecretCode anti‑fuse technology delivers secure, scalable, easy‑to‑integrate one‑time‑programmable memory for sensitive SoC applications.

What You Will Learn:

  • How the SecretCode anti‑fuse architecture provides intrinsic, hard‑to‑reverse security for protected code, data, and encryption keys.
  • How the XSC OTP NVM IP integrates easily into SoCs as a single hard macro with embedded charge pump, dual‑supply support, and factory/field programming.
  • How its robust memory features—16–32 Kbit densities, single‑bit programming, low power, and 10‑year retention—support secure boot, DRM, payments, defense, and more on standard CMOS at 22nm and below.
