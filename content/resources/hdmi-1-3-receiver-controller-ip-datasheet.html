Synopsys HDMI 1.3 Receiver Controller IP Datasheet

The Synopsys HDMI 1.3a Receiver Controller with HDCP datasheet describes a complete, silicon‑proven digital controller solution that enables compliant, secure HDMI input processing in consumer and display SoC designs. Fully compliant with the HDMI 1.3a specification and integrating an HDCP 1.2 decryption engine, this receiver controller supports high‑resolution video, deep color formats, and multi‑channel audio while simplifying system integration and reducing overall design risk when paired with the DesignWare HDMI Receiver PHY.

What You Will Learn:

  • How an HDMI 1.3a–compliant receiver controller enables high‑resolution video reception up to 1080p at 60 Hz and 720p/1080i at 120 Hz
  • How an integrated HDCP 1.2 decryption engine and I²C authentication interface support secure content protection
  • How built‑in color space conversion supports flexible RGB and YCbCr video output formats
