MIPI CSI-2 v3.0: Comprehensive 5G Imaging Solution

VIP Expert

Sep 17, 2019 / 1 min read

Smartphones have become a one-man army by incorporating fancy features like biometric authentication, telemedicine, heartrate monitoring. With increasing market demands and requirements for higher image resolutions, MIPI CSI-2 (Camera Serial Interface) has evolved tenfold from where it first started. MIPI CSI-2 v2.0 is designed for use in smartphones, Internet of Things (IoT) devices, wearables, medical devices, augmented and virtual reality. MIPI Board recently adopted MIPI CSI-2 Specification v3.0 and approved associated CTS documents, refer https://members.mipi.org/wg/All-members/document/download/79549.

MIPI CSI-2 v3.0 provisions a better means of capturing, as well as sensing, various objects at a distance than previous versions by providing a reduced interface wires solution (i.e. by reducing the need for additional I2C/I3C/SPI control interconnect). MIPI CSI-2 v3.0 also makes it possible to selectively process a small part of a picture in such a way that it reduces bandwidth requirement, increases frame rate and resolution specifically for vision (computer & machine) applications.

Synopsys offers comprehensive MIPI CSI-2 verification solution for all existing and next-generation technologies. Synopsys has been closely tracking the evolution of the specification & collaborating with early adopters, to provide a solid and high quality verification IP for advanced designs for Automotive,5G and Imaging applications.

Synopsys VC Verification IP for MIPI CSI-2 supports the latest version of MIPI CSI-2 v3.0 specification and is backward compatible with all the previous versions of MIPI CSI-2 (from v1.1 to v2.1).

MIPI CSI-2 v3.0 adds the following significant enhancements and new key features:

  • Unified Serial Link (USL)
  • Smart Region of Interest (SROI)
  • End-of-Transmission Short Packet (EoTp)
  • RAW24 Pixel Packing

Synopsys VIP delivers enhanced performance and verification productivity gains through its native SV/UVM implementation and native integration with Synopsys VCS and Verdi Protocol Analyzer. Synopsys VIP is delivered with built-in functional coverage and source code Test Suite to accelerate the verification closure and achieve tape-out of first-pass quality designs.
