The more complex chips become, the more computing resources are required to ensure maximum yield, performance, and reliability. The processing and storage demands of design exploration, verification, regression testing, and signoff analysis often exceed the capacity of on-prem data centers.

When capacity wanes, chip design teams have three choices:

  1. Expand data center infrastructure — a slow, capital-intensive process that can delay time-to-market and result in millions in lost revenue.
  2. Lift-and-shift workloads to the public cloud — which often results in data synchronization and management issues in addition to excessive IT overhead.
  3. Adopt a hybrid cloud approach — which enables electronic design automation (EDA) workloads to burst from on-prem systems to the cloud seamlessly and provides the greatest agility, data continuity, and cost efficiency.

Given these options, hybrid cloud solutions — such as those available through Synopsys Cloud — stand out as the clear and best path forward. By extending compute resources and bursting workloads into the cloud during peak demand, design teams can maintain productivity and cost efficiency — without overbuilding infrastructure that remains underutilized during quieter phases of the design cycle.

What’s pushing EDA workloads to the cloud?

Chip design workloads demand massive computing resources. Verification runs stretch into billions of vectors, regression suites multiply, and signoff requires increasingly fine-grained accuracy. Even the most robust in-house compute farms eventually hit their limits.

But capacity isn’t the only reason why chip design teams push their workloads to the cloud.

Leading cloud providers offer access to specialized hardware that can be prohibitively expensive or simply unattainable for on-prem deployment. This includes GPU accelerators that deliver 5-10x performance improvements for analog, mixed-signal, and AI-driven workloads. Similarly, new classes of Arm-based CPUs (e.g., AWS Graviton and Microsoft Cobalt) are only available in the cloud. The exceptional parallel processing capabilities of these technologies can significantly accelerate chip design workflows, making them a game-changer for engineering teams.

Ultimately, company size influences cloud strategy. Large enterprises typically maintain extensive on-prem or colocation resources, turning to the cloud primarily to manage workload spikes during periods of deadline pressure. Mid-size companies are generally more cloud-savvy, with a greater share of their workflows already operating off-premises. Startups, on the other hand, are often “born in the cloud,” leveraging on-demand infrastructure for all of their design activities.

Across all cases, the ability to burst EDA jobs into cloud environments is integral to the company’s success.

The biggest barrier: data management

If cloud elasticity were the only requirement, adoption would already be universal. The real challenge is data. EDA applications demand enormous input datasets — process design kits (PDKs), libraries, verification suites — and generate massive output files for debug and analysis. Moving this data into the cloud manually is a multi-week “lift-and-shift” process that duplicates storage, increases costs, and risks synchronization errors.

While schedulers can easily dispatch jobs to the cloud, those jobs are ineffective if they lack seamless access to design data. In such cases, the cloud simply becomes another silo, isolated from the on-prem environment. Even worse, inefficient data transfers can drive up cloud egress costs as teams pay to bring results back for local analysis. Without a well-architected data strategy, the benefits of a hybrid cloud approach are significantly diminished.

How hybrid cloud transforms the design workflow

The benefits and value of a hybrid approach are fully realized when the cloud becomes an extension of the on-prem environment — not a separate island. A well-architected hybrid approach provides:

  • Real-time synchronization, so jobs always have access to the design’s single source of truth.
  • On-demand caching, which incrementally moves only the data required for a job and reuses it for subsequent runs.
  • Smart output management, directing temporary or non-essential data to cloud storage while synchronizing critical results with on-prem data in real time.

This is exactly what we built with the Synopsys Cloud Hybrid Solution. Designed for the unique demands of EDA, it eliminates manual data wrangling by synchronizing design data between on-prem and cloud environments in real time.

When engineers submit jobs via the scheduler, the system automatically allocates resources and manages data flows. Behind the scenes, it incrementally caches only the files needed for each job, sends critical results back to the on-prem environment in real time, and directs temporary data to cloud storage to minimize egress costs.

The result is a hybrid environment that operates as a unified compute fabric, seamlessly combining the scalability of the cloud with the continuity of on-prem resources. This integration enables teams to achieve faster turnaround times, consistent Quality of Results (QoR), and greatly reduced overhead for setup and data management.

Synopsys Cloud: an agnostic solution

Most hybrid cloud offerings tailored for EDA workloads require customers to standardize on specific storage technologies or cloud providers. That adds cost, limits flexibility, and locks teams into narrow infrastructure paths.

Our approach is different.

The Synopsys Cloud Hybrid Solution is both storage-agnostic and cloud-agnostic. It works with any on-prem storage system and can burst into any major cloud environment. This flexibility means customers can adopt hybrid strategies on their terms, without ripping and replacing infrastructure or being tied to a single vendor ecosystem.

Putting hybrid to the test: our experience with AWS

To validate that our hybrid cloud solution performs under the heaviest workloads, we partnered with Amazon Web Services (AWS) to conduct large-scale stress testing. Six of our flagship EDA tools — including VCS for simulation, PrimeSim SPICE for analog and mixed-signal design, PrimeTime for static timing analysis, and DSO.ai for AI-driven design space optimization — were run in hybrid mode on AWS infrastructure.

Each tool represents a different workload profile with unique input/output patterns and compute demands. By exercising them at scale, we proved that hybrid bursting can handle the heaviest EDA jobs without compromising performance or QoR. In many cases, runtimes in hybrid mode matched or exceeded equivalent on-prem runs thanks to newer, faster cloud CPUs.

Equally important, weeks of setup time were eliminated. Instead of manually identifying datasets, packaging dependencies, and replicating environments in the cloud, jobs were scheduled directly with synchronized access to the required data. The tests also yielded a set of workload-specific recommendations (e.g., which outputs should be directed to cloud-only storage) to help customers optimize hybrid deployments.

Extending compute to meet design deadlines

With limited on-prem capacity and project timelines that won’t wait for infrastructure expansion, bursting EDA workloads to the cloud is a necessity for many design teams. A hybrid cloud approach can deliver the agility and resources needed — exactly when they’re needed. The key is smooth data management, which makes design data instantly accessible to cloud jobs while controlling costs and maintaining QoR.

With the Synopsys Cloud Hybrid Solution, design teams can burst workloads to the cloud without compromising quality or wasting weeks on setup. By bridging on-prem and cloud environments — as well as the data flowing between them — we enable our customers to extend compute capacity when needed while maintaining agility, cost efficiency, and data continuity.
