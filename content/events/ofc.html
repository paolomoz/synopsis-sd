overview

Join us at OFC 2026 where we will showcase a comprehensive portfolio of high-speed connectivity and optical design solutions powering next-generation AI, cloud, and HPC systems. Synopsys’ technologies, spanning Ethernet, PCIe, UCIe, and 224G PHY, are engineered for aggressive performance scaling, robust signal integrity, and seamless multivendor interoperability across optical and electrical environments. Ansys Optics Multiphysics solutions complement this offering with advanced simulation software for robust design, optimization, and verification, enabling precise multiscale system design from nano to macro scale and accelerating the development of innovative optical products.

Live Demonstrations

style
tinted, pt-md, centered
anchor
demonstrations

Synopsys — Booth #615, South Hall

  • 224G IP Over Optics
    • Featuring Synopsys 224G PHY IP showcasing interoperability with AOI Linear Pluggable Optics (LPO), highlighting seamless electrical‑to‑optical integration required to scale bandwidth while managing longer reach, lower power, and signal integrity constraints.
  • PCIe 7.0 Over Optics
    • Featuring Synopsys PCIe 7.0 PHY IP, successfully showcasing interoperability with MACOM’s MAEQ‑39966 redriver and MACOM’s TIA and VCSEL driver, demonstrating robust long‑reach PCIe connectivity and validating ecosystem readiness for extended‑distance, high‑performance system designs.
  • UCIe IP Demonstration
    • Featuring Synopsys UCIe PHY IP, showcasing power‑efficient, high‑bandwidth die‑to‑die connectivity and enabling scalable chiplet‑based systems through standards‑based heterogeneous integration.
  • Multiphysics Analysis for CPO
    • A demonstration showcasing advanced Multiphysics simulation for Co-Packaged Optics (CPO) using Ansys Lumerical FDTD, Ansys Lumerical Multiphysics, Ansys Zemax OpticStudio, and Synopsys technologies.
  • Accelerating Simulation with GPU
    • A demonstration of GPU acceleration in electronic photonic design automation (EPDA) including rapid analysis and optimization for on-chip grating couplers and advanced electro-optic circuits.

Partner Booths

style
tinted, pt-sm

Ethernet Alliance Interoperability Showcase — Booth #5023, West Hall

  • Featuring Synopsys 800G Ethernet IP Solution showcasing an end‑to‑end 800G Ethernet system interoperating with Arista and Viavi 800G platforms via Arista OSFP 2m DAC links.
  • Featuring Synopsys 800G Ethernet IP Solution, this demo demonstrates seamless multi‑vendor 800G Ethernet operation across Cisco and Keysight platforms using HyperPhotonix DR8 optics and OSFP DAC connectivity.

OIF Interoperability Showcase — Booth #2017, South Hall

  • Featuring Synopsys 224G PHY IP interoperability with ecosystem vendors using Direct Attach Copper (DAC)/Active Copper Cable (ACC) demonstrating reliable operation across passive and active copper solutions and reinforcing deployment flexibility for next‑generation fabrics.
  • Featuring Synopsys 224G PHY IP interoperability with ecosystem vendors using Linear Pluggable optics (LPO), showcasing excellent signal integrity and power efficiency with LPO, a key enabler for scalable, energy‑efficient ultra‑high‑bandwidth systems.

Samtec — Booth #1101, South Hall

  • Featuring Synopsys 224G PHY IP on the Samtec SiFly HD 224G cabled backplane platform, this demo validates an end‑to‑end 224G channel and demonstrates ecosystem readiness for next‑generation systems based on 224G PHY.
