overview

Synopsys Security Protocol Accelerator (SPAcc) IP provides increased performance, ease of use, and advanced security features such as QoS and virtualization. It supports cryptographic acceleration for major security protocols such as IPsec, TLS/DTLS, WiFi, MACsec, and LTE/LTE-Advanced.

Also available is an automotive grade Security Protocol Accelerator that has been certified by SGS-TÜV for functional safety ISO-26262 ASIL B level compliance. Specifically, the achieved safety integrity level is ASIL D for systematic faults and ASIL B for random hardware faults.

Synopsys provides designers with cost- and power-efficient security solutions that can be configured to provide specific functionality and meet the performance requirements of the target application.

The SPAcc IP product family offers designers unprecedented configurability to address the complex security requirements that are commonplace in today's multi-function, high-performance SoC designs.
