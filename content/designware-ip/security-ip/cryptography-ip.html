Configurable & Secure

Synopsys offers a broad portfolio of silicon-proven Synopsys Cryptography IP solutions that include symmetric and hash cryptographic engines, Public Key Accelerators (PKAs), True Random Number Generators (TRNGs) and Physical Unclonable Function (PUF). The hardware and software security implementations are highly configurable, cover a wide spectrum of size and performance combinations and are available in different architectures, such as look-aside or flow-through.
