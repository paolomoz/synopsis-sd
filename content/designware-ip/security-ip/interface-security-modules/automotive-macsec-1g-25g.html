Data security for Ethernet-connected devices is growing due to increasing sensitive data, new regulations, and advancements in cloud, mobile/5G, and automotive technologies. Media Access Control Security (MACsec) is the key Layer 2 protocol protecting network communications from threats like DoS and eavesdropping by establishing secure links.

Synopsys MACsec Security Modules use scalable AES-GCM cryptography to provide confidentiality, integrity, authentication, and replay protection for Ethernet traffic. These modules integrate seamlessly with Synopsys Ethernet MAC & PCS IP, supporting high data rates with low latency. By incorporating Synopsys MACsec Security Modules into Ethernet IP solutions, networking SoC designers can ensure end-to-end security for data in motion between Ethernet-connected devices.

Besides traditional MACsec solutions, Synopsys also offers the first automotive-certified MACsec for functional safety (ASIL B / ISO 26262), cybersecurity (ISO/SAE 21434), and AI safety (ISO/PAS 8800) compliance. This IP variant protects against random and systematic faults, where reliability and fault tolerance are paramount. It meets the stringent safety process and documentation requirements of ISO 26262, with ASIL D level of compliance for systematic faults, the highest safety integrity level for automotive applications.

Synopsys Automotive MACsec IP has been fully certified by SGS-TÜV for SAE/ISO 21434 cybersecurity process, ASIL B, as well as ISO/PAS 8800 AI Safety compliance.

Highlights

  • Supports IEEE 802.1AE - MACsec standard
  • Supports IEEE 802.1Q – Frame preemption, VLAN in-the-clear
  • Extended packet numbering as per IEEE 802.1AEbn standard
  • Automotive-compliant: ASIL B / ISO 26262 / ISO 21434 / ISO 8800
  • Seamless integration with Synopsys Ethernet and PCS IPs
  • Per frame processing, including encapsulation/decapsulation and frame validation
  • Scalable throughput for Automotive solutions: 1G-25G Gbps
  • Based on state-of-the-art, highly optimized AES-GCM crypto
  • Configurable for optimal latency and PPA
  • Scalable number of secure channels and secure associations
  • FIPS 140-3 certification ready
  • Jumbo frames support
  • SecTag insertion & removal
  • Supports multiple VLAN tags lookup modes
  • MII/SGMII/GMII/XGMII/XLGMII/RMII/RGMII interfaces
