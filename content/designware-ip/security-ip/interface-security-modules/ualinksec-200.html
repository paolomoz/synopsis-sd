UALink serves as a critical interface in data centers, designed to facilitate scaling up AI networks enabling high-speed data transfer across multiple lanes. Its primary purpose is to ensure efficient communication between various components within a data center, supporting up to 200 GT/s per lane and accommodating configurations of up to four lanes. This capability is essential for managing the vast amounts of data processed in modern data centers, enabling seamless integration and operation of complex systems.

The protection of data traveling across the UALink interface is paramount due to the sensitive nature of the information being transmitted. Ensuring data security involves implementing robust encryption and authentication mechanisms to safeguard against unauthorized access and data breaches. Encryption is mandatory to maintain confidentiality, while authentication, though optional, enhances the security framework by verifying the integrity and origin of the data. These measures are crucial to prevent data from being intercepted or tampered with during transit.

Synopsys UALinkSec_200 Security Module is specifically designed to address the security needs of the UALink interface, with focus on the UALinkSec component from the UALink 200 v1.0 specification. This module provides highly efficient encryption and decryption capabilities based on the AES-GCM cryptographic algorithm, ensuring data remains secure throughout its journey. Additionally, it offers key derivation functionality and optional authentication support, allowing for flexible security configurations tailored to specific requirements. By using this security module, which comes pre-integrated with Synopsys UALink modules, data centers can achieve failsafe secure operations, minimizing the risk of data exposure and enhancing overall system integrity.

Synopsys’ complete UALink IP, including silicon-proven 224G PHY, controller, security and verification IP, delivers a low-risk, secure solution optimized for power, performance, area, and latency.
