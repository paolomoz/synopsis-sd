The Synopsys Inter-IC Sound (I2S) Controller IP bus is a simple three-wire serial protocol to transfer stereo audio data. It has been a popular low-cost interface for digital audio since the 1980s for both input analog front-ends for microphones as well as output into speakers, DACs, Class D amplifiers. Recently, Time Division Multiplexing (TDM) has gained popularity to address multi-channel high resolution audio requirements in mobile, smart home, PC, AR/VR, automotive HMI and beyond, such as, sensing applications for access management and always-on operation. The Synopsys I2S offering covers traditional I2S Philips mode, advanced selections for left and right justification, DSP mode and TDM operation. In TDM mode, the IP provides users several levers like programmability of number of slots, slot length etc. which cover the myriad of use-cases in the market. Multi-lane operation adds the necessary bandwidth to enable expedited transfers.

Highlights

  • Area optimized next generation I2S/TDM Controller
  • I2S transmitter and/or receiver based on the Philips I2S protocol
  • Full duplex operation • Multi-lane option with programmable enable/disable for each transmitter and receiver lane
  • Programmable audio data resolutions
  • Programmable external sclk gating and enable signals
  • Configurable and programmable word select length
  • I2S Left and Right Justified format
  • TDM and DSP modes
  • Programmable slots in a single TDM frame
  • Programmable slot length to reduce the high serial clock frequency
  • Programmable LSB or MSB first endianness
  • Programmable offset cycles for the data
  • Programmable duty cycle of the frame synchronization signal (word select)
  • I2S Mode is compatible with Display Port (DPTX) Controller
