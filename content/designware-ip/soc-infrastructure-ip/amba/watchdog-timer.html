Synopsys Watchdog Timer

Talk to an Expert

The Synopsys Watchdog Timer provides a reliable solution that is software programmable to easily adapt to your application needs such as system wake-up and reset. It conforms to the AMBA® APB bus interface specification and has a clock pre-scaler for external high-frequency sources.

The device works with two fully independent clocks: the APB bus clock for accessing control and status registers, and a separate timer clock for the main Watchdog Timer function, so the APB bus clock may be switched off while the timer remains active. The interrupt generation is active even if the APB clock is stopped. These features make the Synopsys Watchdog Timer the perfect fit for low-power systems.

Highlights

  • Key Benefits:
  • Low Power friendly implementation
  • Low level device driver included
  • Industry standard interfaces (AMBA® APB)
  • Area efficient
  • Watchdog Timer Support Features:
  • AMBA APB interface
  • Clock prescaler for external high frequency sources (creating a 64-bit programmable counter value)
  • Two fully independent clock domains
  • apb_clk domain for accessing control and status registers
  • timer_clk domain for the timer/counter function
  • Reset synchronization circuit
  • Interrupt generation active even if the APB clock is switched off
  • Power saving features
  • APB clock may be switched off
  • Timer enable/disable under software and hardware control
  • Security key to prevent unintentional accesses to critical control registers
  • Typical Applications:
  • System Wake-Up: Wake up a system from sleep mode
  • System Reset: Reset a system that fails to respond on interrupts to prevent system hang-up
