The Synopsys AVSBus Controller IP is a configurable, synthesizable, and programmable IP that provides point-to-point communication per AVSBus v1.4.1 of PMBus Specification Part III. The IP supports an AMBA APB completer port for host application interfacing and software programming. The controller can be used for AVSBus simple and efficient command set optimized specifically to implement adaptive voltage scaling.

AVSBus is an emerging power management standard defined by System Management Interface Forum (SMIF) to allow Adaptive Voltage Scaling in High-performance Compute, Edge AI, PCs and Industrial applications. As performance of devices increases multi-fold in modern HPC and AI applications, so does their demand for power and thermal management. AVSBus is a complementary standard to PMBus for fine-grained and dynamic power control at the point-of-load between SoCs and Power Management devices.

The AVSBus protocol covers a wide range of power system architectures and converters. It comprises a 3-wire interface for communication rates up to 50MHz (x50 of PMBus). The protocol defines standard commands and error management for ecosystem interoperability.
