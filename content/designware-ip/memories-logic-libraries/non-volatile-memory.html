Get Started

Synopsys Non-Volatile Memory (NVM) IP offers One-Time Programmable (OTP), Few-Time Programmable (FTP) and Multi-Time Programmable (MTP) NVM solutions for code storage, configuration, calibration, and security across a wide range of applications—automotive, industrial and consumer. For applications requiring enhanced protection, the Secure Storage Solution for OTP IP adds dedicated hardware-level security.

Supporting densities from 16 bits to 1 Mbit, Synopsys NVM IP is available in standard CMOS, BCD, HV, embedded flash, and specialty processes—without extra masks or process steps, enabling cost‑efficient integration and broad foundry availability.

Engineered for high performance, low power, and reliability, the IP supports endurance up to 1,000,000 cycles, high‑temperature operation for automotive environments, and meets AEC‑Q100 Grades 0, 1, and 2 on select nodes. Each NVM instance undergoes comprehensive characterization, JEDEC/JESD qualification, and reliability testing. With antifuse OTP technology and availability from 180 nm to advanced nodes, Synopsys NVM IP is silicon‑proven in thousands of designs.

Optimized architecture and configurations ensure strong PPA and manufacturability, making Synopsys NVM IP a secure, scalable, and robust solution for modern SoCs.

Synopsys advanced node OTP is silicon-verified in TSMC's N7, N7A N6, N5, N5A, N4P, and N3P processes. Synopsys OTP in TSMC N5A and N7A is Grade 1 qualified to the AEC-Q100 standard.

        What is Non-Volatile Memory (NVM)?

        Non-volatile memory retains data even when power is removed, making it essential for storing configuration settings, security keys, firmware, and other critical information. By using NVM IP from a vendor like Synopsys, chip designers can efficiently add reliable, tested NVM functions to their designs without developing the technology from scratch. Learn more

        Why kind of NVM IP Solutions does Synopsys provide?

        Synopsys NVM IP offers OTP, FTP, and MTP memories from 16 bits to 1 Mbit in standard CMOS, BCD, high voltage, and specialty technologies—no extra masks needed. It delivers industry-leading reliability, up to 1,000,000 cycles, high-temperature operation, and ultra-low power. Selected IP meets AEC-Q100 Grade 0, 1 or 2 standards and is rigorously designed for quality and tested for reliability. Synopsys Secure Storage Solution for OTP provides hardware-based data protection.

        How can I easily select the NVM by Foundry & process technology for my SoC?

        Find the best NVM IP for your SoC design by selecting your foundry, process node, and more in the NVM IP Selector

        What are the key use cases and applications for OTP NVM?

        One-time programmable (OTP) NVM provides non-volatile storage that supports power, form factor, and security requirements for a variety of use cases, including code storage, encryption keys, analog trimming, and IC configuration. Typical applications include Power Management ICs (PMICs), sensors, home entertainment, automotive, industrial, mobile, aerospace & defense, and IoT products. Learn more

        Why is Synopsys OTP NVM IP the preferred choice for advanced FinFET nodes in SoC design?

        Synopsys NVM OTP is preferred for advanced FinFET nodes because it offers high scalability, security, and is crucial for first-pass silicon success, especially when using antifuse technology. While thinner oxides in advanced nodes pose challenges, Synopsys OTP IP solutions are designed to be reliable across various conditions for securely storing critical data like encryption keys, device IDs, analog trimming and IC configuration. Read article

        What benefits do Synopsys OTP and MTP NVM IP solutions provide for PMIC design and configuration?

        Power Management ICs (PMICs) rely on Synopsys OTP and MTP NVM IP for efficient calibration and configuration. These solutions offer reliable, secure, and area-efficient embedded memory in standard CMOS and BCD processes, without extra steps. Synopsys NVM IPs enable flexible PMIC designs, supporting both factory-programmed and reconfigurable applications, and are widely used in consumer and automotive systems. Learn more

        What is Synopsys Secure Storage Solution for OTP IP?

        Synopsys Secure Storage Solution for OTP is an add-on to Synopsys OTP NVM IP in advanced process nodes. It is designed to address the need for hardware-based security in embedded NVM for AI, HPC, IoT, Aerospace & Defense, and Automotive applications. Learn more
