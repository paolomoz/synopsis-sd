The Synopsys DisplayPort TX IP solution consists of DisplayPort 1.4 and 2.1 PHY IP, DisplayPort TX Controller IP with HDCP 2.3 content protection, verification IP, IP prototyping kits, and IP software development kits (SDKs). These elements accelerate development of advanced chip designs delivering audio, video, and data over a single DisplayPort connector. The Synopsys DisplayPort TX IP solution is targeted for integration into SoCs that support connections to high-definition (HD), 2K, 4K, and 8K Ultra High Definition (UHD) display from mobile devices, set-top boxes, and other applications requiring fast data transfer and output of high-resolution content.

Highlights

  • VESA certified Synopsys DisplayPort Tx solution
  • Supports RBR, HBR1, HBR2, and HBR3 bitrates for 1.4 designs
  • UHBR10, UHBR13.5 and UHBR20 bitrates are also supported for >2.0 designs
  • Controllers support DisplayPort TX with HDCP 2 content protection
  • Solution includes PHY IP, controller IP Verification IP, PHY board, DSC Encoder, HDCP IP, TRNG IP and IP Software Development Kits
