Get Started

The comprehensive USB 2.0 IP offering consists of controllers (OTG Host, Device and Dual Role, EHCI/OHCI Host, and controllers optimized for IoT edge applications), PHYs with support for USB Type-C™ connectivity, Verification IP, IP Prototyping Kits, and IP subsystems. These elements enable quick development of advanced chip designs incorporating the 480 Mbps USB 2.0 standard (including High Speed, Full Speed, and Low Speed).

The USB 2.0 IP supports Type-C connectivity with the Synopsys IP USB-C 2.0 IP, which simplifies users’ USB connection with reversible plug orientation and cable direction, and bi-directional power. The Synopsys IP USB-C 2.0 IP also supports features required for the USB Audio Device Class 3.0 specification to enable USB audio over Type-C connections.

The Synopsys IP eUSB2 IP solution provides designers with IP for low-power mobile and consumer products, such as smartphones, tablets, laptops, and wireless communication devices, that are designed in the most advanced process nodes.

The Synopsys IP eUSB2 IP solution includes USB Digital Controllers, eUSB2 PHYs, eUSB2 Repeaters, Verification IP, and IP Subsystems expertise.

  • Saves engineering effort with USB IP Subsystem, PHY, and Controller
  • Saves area with smallest combined solution area
  • Saves BOM costs with integrated features
  • Saves software effort with standard drivers that are compatible with open sources

As the leading supplier of USB IP, Synopsys provides designers with a high performance, low power and area efficient IP solution, for cost effective integration into system-on-chip designs. Synopsys’ expertise in developing and supporting USB and high-speed SerDes architectures enables us to build low risk, high quality USB IP solutions.
