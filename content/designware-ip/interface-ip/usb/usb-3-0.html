Get Started

The Synopsys IP SuperSpeed USB IP solution is based on the USB 3.0 specification from the USB Implementer Forum. The comprehensive SuperSpeed USB IP offering consists of the host, device, and dual-role device (DRD) controllers, PHYs with and without support for the USB Type-C™ connectivity specification, verification IP, IP Prototyping Kits, and IP subsystems. These elements enable quick development of advanced chip designs incorporating the 5.0 Gbps SuperSpeed USB standard.

  • Saves engineering effort with USB IP Subsystem, PHY, and Controller
  • Saves area with smallest combined solution area
  • Saves BOM costs with integrated features
  • Saves software effort with standard drivers that are compatible with open sources

The Synopsys IP SuperSpeed USB IP is targeted for integration into SoCs for media storage, creation, and playback devices, requiring high bandwidth for faster “sync-and-go” functionality between PCs and portable electronic devices. The Synopsys IP SuperSpeed USB Digital Controller and PHY enable the fastest SuperSpeed USB data transfer speeds while lowering overall power consumption.

The IP supports Type-C connectivity with the Synopsys IP USB-C 3.0 IP, which simplifies users’ USB connection with reversible plug orientation and cable direction, and bi-directional power. The Synopsys IP USB-C 3.0 IP also supports features required for the USB Audio Device Class 3.0 specification to enable USB audio over Type-C connections.

As the leading supplier of USB IP, Synopsys provides designers with a high performance, low power and area efficient IP solution, for cost effective integration into system-on-chip designs. Synopsys’ expertise in developing and supporting USB and high-speed SerDes architectures enables us to build a low risk, high quality SuperSpeed USB IP solution.
