Talk to an Expert

Synopsys provides designers with silicon-proven, configurable USB 3.1 Controllers. The Synopsys USB 3.1 controllers provide the lowest possible gate count, efficient power management optimized with dual power rails, and PIPE and UTMI/UTMI+ interfaces for PHYs. This comprehensive solution includes support for Dual Role Device (DRD), xHCI Host, and Device.

Synopsys USB 3.1 Controller IP offers the flexibility required for high-volume, fast turnaround consumer applications. Configuration options maximize SoC design performance and minimize CPU interrupts, while flexible parameters enable easy integration into low- and high-latency systems.

Synopsys USB Controller IP has shipped in almost two billion units for leading electronics companies worldwide. Using Synopsys USB IP significantly reduces development time and engineering risk, bringing USB-based SoCs to market faster.

Synopsys USB IP is the most certified IP solution in the industry. With over 3,000 design wins, Synopsys' complete USB IP solution--consisting of controllers, PHYs, verification IP, drivers, and IP prototypes--enables designers to lower integration risk and speed time-to-market.
