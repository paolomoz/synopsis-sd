The Synopsys Ethernet for Scale-Up Networking (ESUN) IP solution, is the industry’s first complete Layer 1 and Layer 2 IP offering purpose-built for Ethernet-based AI scale-up networks. The solution comprises a 1.6T multi-rate Ultra Ethernet MAC, a 1.6T multi-rate Ethernet PCS with RS-FEC, a dedicated UEC/ESUN Link Layer Controller implementing Link-Level Retry (LLR) and Credit-Based Flow Control (CBFC), silicon-proven 224G Ethernet PHY IP, and verification IP including an ESUN-ready SoC Verification Kit (SVK). The ESUN IP solution delivers low latency, lossless reliability, and high throughput efficiency required by next-generation AI/HPC scale-up fabrics compliant with the OCP ESUN (Ethernet for Scale-Up Networks) specification.

The solution is based on the evolving IEEE 802.3dj Ethernet standard and supports Ultra Ethernet Consortium (UEC) defined link-layer enhancements LLR for lossless reliability and CBFC for fine-grained congestion management. The IP solution supports interconnect rates of 1x1.6T, 2x800G, 4x400G, and 4x200G Ethernet over 224G SerDes, and 1x800G, 2x400G, 4x200G, and 4x100G Ethernet rates over 112Gbps SerDes.

Highlights & Key Features

Highlights

  • Complete Layer 1 and Layer 2 Ethernet IP solution including MAC, PCS, UEC/ESUN Link Layer Controller, 224G PHY, and VIP
  • Supports OCP Ethernet for Scale-Up Networks (ESUN) v1.0 specification for AI/HPC scale-up fabrics
  • Built on Ultra Ethernet Consortium (UEC) architecture with support for Link-Level Retry (LLR) and Credit-Based Flow Control (CBFC) for enhanced link-level reliability and flow control
  • UE/ESUN Link Layer Controller implements dedicated LLR and CBFC management controllers, and performs Control Ordered Sets (CtlOS) insertion and extraction
  • Optimized for low latency, high throughput communication in a scale-up fabric
  • Supports 1.6T, 2x800G, 4x400G, and 4x200G Ethernet rates over 224Gbps SerDes
  • Supports 1x800G, 2x400G, 4x200G, and 4x100G Ethernet rates over 112Gbps SerDes
  • Supports evolving IEEE 802.3 and OIF-224G electrical standards, meeting performance criteria for chip-to-chip, chip-to-module, and long reach copper/backplane interconnects
  • High-performance receiver equalization, supporting channel loss up to 45dB
