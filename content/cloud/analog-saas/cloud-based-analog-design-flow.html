Analog Instance Technical Paper

The Synopsys Cloud Analog Instance enables a full analog design environment that provides a complete end-to-end design flow with access to all Synopsys and many leading 3rd-party solutions. The design environment:

  • Eliminates the need to maintain a CAD infrastructure
  • Facilitates all design steps including schematic design, circuit simulation, layout creation, in-design analysis, extraction, verification and signoff
  • Provides automated PDK and technology setup in a secure environment
  • Best-in-class circuit simulation performance using multi-core and GPU-accelerated options
  • Creates and migrates design using a template based in-design analyses using StarRC and IC Validator
