Synopsys Cloud has multiple major releases each year. Utilizing the tenets of agile engineering allows Synopsys Cloud to keep pace with your needs and offer new features and capabilities on a frequent basis. Check out the latest release details below.

Release 10.x

Synopsys Cloud 10.x introduces GitHub native EDA workflows, improved visibility through centralized notifications, and access to new GenAI verification assistants to further boost engineering productivity.

Release 10.x includes:

  • GitHub Apps: Run Synopsys EDA checks directly from GitHub pull requests and comments to enable continuous, collaborative hardware development workflows.
  • Notification Center: A new portal experience that centralizes critical notifications and alerts for improved operational awareness.
  • New GenAI verification apps: Expanded access to Synopsys GenAI applications, including verification assistants such as the Unit Testbench (TB) Agent and Verdi Assistant.

Release 9.x

Synopsys Cloud 9.x, released in December 2025, brings smart tools into the portal to help understand license usage and answer questions about Synopsys Cloud. It also enables access to a growing list of GenAI applications from Synopsys.ai.

Release 9.x includes:

  • Synopsys Cloud Assistant: Get quick answers about your Synopsys Cloud account with this assistant built into the Synopsys Cloud portal
  • Pay-Per-Use: Control spend through improved Pay-Per-Use budget governance
  • License analytics: View product level usage analytics to make informed project planning decisions
  • Storage: New storage offering in SaaS that lowers costs by up to 50%
  • Synopsys.ai Copilot: Streamlined access to GenAI applications from Synopsys to boost engineering productivity

Release 8.x

Synopsys Cloud 8.x, released in June 2025, adds several new capabilities to the Synopsys Cloud platform including access to Ansys products, access to Synopsys.ai CoPilot GenAI suite of apps and an enhanced cloud portal experience, further boosting the productivity of chip design engineers and CAD managers.

Release 8.x includes:

  • Synopsys.ai Copilot: From within the Synopsys Cloud portal, easily enable your team's access to Synopsys GenAI-based assistive applications such as Knowledge Assistant
  • API Support: Enhanced API support to download all license logs and usage reports
  • Storage Improvements: ANF backup and restore for SaaS customers, plus a new data sync service between your on-prem storage and SaaS storage
  • Design Enablement Central (DEC): Improved portal experience for a DEC administrator to manage budget and licenses including advanced capabilities to control and allocate licenses to different divisions or entities
  • Ansys Products: Ansys' semiconductor products are now available via the Synopsys Cloud portal as Cloud Subscription Licenses (CSL)

Release 7.x

Synopsys Cloud 7.x, released in November 2024, expands the existing license automation capabilities and compute environment to make it even easier for you to manage your EDA licenses and design environment.

Release 7.x includes:

  • Design Enablement Central (DEC): An enterprise-level extension to the Synopsys Cloud portal enables license and budget allocation to divisions or entities
  • License Analytics: New charts provide actionable data on license usage and denials to guide future purchasing decisions
  • License Governance: Convenient access via API and portal to activate FlexLM options files and retrieve logs and reports
  • Compute Infrastructure: Expanded storage, compute and other infrastructure options to configure a customized chip design environment suited for your needs
  • Synopsys IP: Manage access to your Synopsys IP from within the Synopsys Cloud portal

Release 6.x

Synopsys Cloud 6.x, released in March 2024, amplifies your chip design capabilities by blending the power of cloud-native EDA tools with pre-optimized compute resources. Access unlimited EDA software licenses by the minute through the novel FlexEDA business model and pay for only what you use in real time. With the addition of advanced features such as complete license management automation, enhanced analytics, and the availability of multi-vendor flows, the platform empowers you to design higher quality chips, faster. Dive into an optimized ecosystem without disrupting your established EDA flows, and let Synopsys Cloud redefine your design horizon.

Release 6.x includes:

  • Hybrid Cloud: Synopsys Cloud cansplitajob between cloud and on-prem compute resources based on available capacity, and the jobs run simultaneously. All of the data generated by the job is synchronized in real-time between the cloud and on-prem, so there is no need to manually transfer data.
  • End-to-End License Management Automation: Eliminate license management bottlenecks and overhead by leveraging Synopsys Cloud license management service for on-premise, SaaS or BYOC from any public cloud with in-app license purchase, instant activation, availability and unlimited scalability.
  • SOC 2® Type 2 Certification: Demonstrates Synopsys Cloud's adherence to critical security standards that safeguard your data against unauthorized access, by following trusted industry principles of security, availability, processing integrity, and confidentiality.
  • Enhanced User Experience with Portal 2.0: A complete portal UI refresh with a scalable and modular backend engine and front end-support for cutting edge features including granular budget governance, dynamic scaling of compute clusters, heterogenous compute clusters for full flow automation, and detailed usage analytics at tool, user or infrastructure level.
  • Enhanced Scheduler Support: Leverage LSF, UGE or Slurm across multiple deployment options, depending on your needs.

Release 1.x-5.x

Synopsys Cloud, launched in March 2022, introduces a first of its kind modern, convenient and effective way of managing EDA environments through advanced license management capabilities, industry's first true Pay-Per-Use licensing and the flagship EDA-as-a-Service offering which provides a one-stop ready-to-go chip design environment.

  • Modern Interface: Web-based portal to manage your EDA environment where you can purchase and instantly deploy EDA licenses and compute infrastructure, define license and budget governance, and view analytics on budget spend and license usage
  • Deployment Options: Flexibility to leverage Synopsys Cloud's advanced license management capabilities regardless of where your compute resources reside
  • BYOC: Bring Your Own Cloud/Compute to connect to Synopsys Cloud managed license servers from a customer managed chip design environment
  • SaaS: Get your chip design environment up and running quickly with Synopsys Cloud’s one-stop shop which provides the essential components including compute options for various types of EDA workloads, storage, unix desktop, scheduler, and Synopsys EDA licenses and software
  • FlexEDA Licensing: Offers the traditional term-based, prepaid licensing, plus the industry's first true Pay-Per-Use licensing that provides Synopsys’ flagship EDA products by the minute. Pay-Per-Use is built on the now patented metering technology.
  • Analytics: Detailed dashboards provide actionable insights into budget spend and license usage for project and budget planning
  • Governance: Complete control over license access through FlexLM options file and web UI controls. The portal also allows you to manage budget spend per user, team or project
