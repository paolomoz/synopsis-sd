License Management Automation

Synopsys Cloud eliminates the complexity of managing licenses and license servers in a fast, scalable, and fully automated way. Through a modern web interface, CAD managers can completely manage EDA licenses and access to them, including:

  • Purchase and activate term-based licenses instantly with just a few clicks
  • Enable Pay-Per-Use metering that allows unlimited access to Synopsys’ flagship applications at a per-minute rate
  • View analytics on budget and license usage to plan and optimize for projects
  • User-based or project-based license access and budget governance
  • Synopsys IP users can enable their IP licenses to be brought into the Synopsys Cloud portal with just a click of a button

FlexEDA Licensing Model

FlexEDA offers flexible licensing models – a term-based Cloud Subscription License and the industry’s first, patented Pay-Per-Use licensing.

  • Cloud Subscription License (CSL): If you prefer to plan ahead, the CSL model provides the familiar fixed-number, term-based license access.
  • Pay-Per-Use (PPU) licensing: This model offers unparalleled flexibility and grants unrestricted on-demand access to Synopsys’ flagship applications at a per-minute rate. The metering algorithm monitors the jobs for the number and duration of licenses checked out and charges the user accordingly. This removes traditional license barriers and unlocks unlimited parallel processing, slashing time-to-results from weeks to mere minutes.
  • Combine CSL and PPU: The combination of CSL and PPU via FlexEDA licensing allows the flexibility needed to cater to the changing EDA needs of a chip design project.

Deployment Options

With the Synopsys Cloud platform, you can take advantage of advanced license management irrespective of where the compute environment is deployed:

  • Bring Your Own Compute (BYOC): This is a customer-managed environment, whether it is an on-prem data center or on the cloud such as AWS, Google Cloud Platform, HPE, and Microsoft Azure.
  • Synopsys managed SaaS environment: This is a fully managed, web-based, ready-to-go design environment that can be setup within a day and provides access to all the infrastructure necessary for chip design work, including numerous compute and storage options, schedulers, UNIX desktop, and Synopsys EDA products installed.
    The environment is enabled with Role Based Access Control (RBAC). A designated CAD manager can manage projects, users, compute resources, EDA licenses, license access and also monitor budget and license usage - all within the Synopsys Cloud portal.

Hybrid Cloud


The Synopsys Cloud hybrid solution enables design teams to burst EDA workloads to the cloud securely, seamlessly, and quickly. A designer simply submits EDA jobs to their scheduler on-prem and the secure hybrid solution takes care of the rest — leveraging cloud compute capacity as needed. The designer does not need to manually move any data from on-prem to the cloud environment for jobs that run on the cloud. Instead, all of the data needed and generated on the cloud is synchronized automatically in real-time between the cloud and on-prem and is available for analysis and debug.
