Seamless Interoperability for the Semiconductor Design Ecosystem in the Cloud

The Synopsys Cloud OpenLink Program enables a multi-vendor environment of EDA, IP and foundry solutions so chip designers can easily access their preferred vendors’ products in the Synopsys Cloud environment. The Synopsys Cloud OpenLink application programming interface provides highly secure system-to-system interoperability, allowing chipmakers to easily assemble their design environment on Synopsys Cloud:

  • Products from different vendors can be accessed easily from the Synopsys Cloud environment
  • Design teams are able to focus on what they do best: developing better quality chips, faster

Program Member Benefits

  • Streamlined deployment
  • Pre-defined legal terms
  • Highly secure entitlement and license enablement
  • Joint ecosystem outreach
  • Close technical collaboration on cloud

Synopsys Cloud OpenLink API Benefits

  • System-level integration with one-time setup
  • Customer-partner transaction encapsulation
  • Exposure to Synopsys Cloud customers
  • Member controls customer access on Synopsys Cloud

Synopsys Cloud OpenLink API

The Synopsys Cloud OpenLink API provides highly secure system-to-system interoperability with Synopsys Cloud, allowing chipmakers to easily assemble their design environment on Synopsys Cloud. Via the API, foundries and EDA and IP vendors can deliver product entitlements and license files directly to the Synopsys Cloud for use by their customers.
